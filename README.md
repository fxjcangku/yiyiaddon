# yiyiaddon

Minecraft Java 版（26.1.2 + Fabric）的客户端扩展模组。

## 本仓库是什么

- 本仓库是**发布页**：只放编译并混淆后的发布产物与版本说明。
- **不公开源码**，仓库内不提交任何源码文件。
- 下载请到本仓库的 Releases 页面。

## 安装

1. 装好对应 Minecraft 26.1.2 的 Fabric Loader。
2. 把下载到的 `.jar` 放进 `.minecraft/mods/`。
3. 启动游戏。
