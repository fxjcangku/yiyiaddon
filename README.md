yiyiaddon 是一个独立的 Fabric 客户端模组，为 Minecraft 26.1.2 与 26.2 提供成体系的自动化能力。它不依赖 Meteor 或其他客户端框架；模块、设置、状态与日志统一收进一套中文控制中心。

这里不只放一组“自动点击”开关。每套核心系统都包含自己的识别、规划、执行、异常恢复和状态反馈：农场会认识服务器里的作物与季节，钓鱼会判断真实运动状态，挖矿会管理目标、路径、战斗和补给。

> **项目刚移植，部分模块与模式未测试，遇到 BUG 请反馈。**

## 核心系统

| 系统 | 解决的问题 | 关键能力 |
| :--- | :--- | :--- |
| **星露谷农场** | 服务器作物、盆栽、季节与工具各不相同 | 资源识别、分区种植、成熟判定、四季规划、洒水与后勤 |
| **自动钓鱼** | 上钩时机、网络抖动与打开背包时的输入状态 | 运动预测、收竿判定、状态恢复、背包场景兼容 |
| **种子挖矿** | 远处矿物不可见，服务器还可能伪装方块 | 本机离线预测、真实方块验证、世界标记、自动挖掘联动 |
| **自动挖矿** | 挖矿不是一次破坏，而是一整条工作班次 | 寻路采掘、连锁挖矿、战斗、卸货、进食、工具维护 |
| **农场后勤** | 自动化最容易卡在缺种子、满背包和箱子错位 | 容器绑定、定量补货、成品卸货、点位与服务器隔离 |

### 星露谷农场

进入服务器后，模组从当前服务器的资源包学习真实存在的作物、种子、种植盆和工具，再把它们用于种植计划。数据按服务器隔离，换服不会带走上一台服务器的农田与名单。

- 单作物区与混种区可以同时存在，每种作物有独立配额。
- 自动处理播种、浇水、施肥、药剂、收获、枯死株与洒水器维护。
- 识别 HUD 中的季节与天数，让季节限制真正参与播种决策。
- 种子箱、成品箱、补水点和农田点位形成完整后勤闭环。
- 中文状态、范围渲染和运行日志用于解释“现在为什么这样做”。

### 星露谷钓鱼与自动钓鱼

自动钓鱼不是固定延迟点击。它持续观察浮漂的运动、方向与时间关系，区分普通波动、网络积压和真实咬钩，再决定何时收竿。

- 在正常游戏、GUI 与背包打开状态下保持一致的计时与点击逻辑。
- 对高频更新、反向运动、过期证据和网络抖动设置独立保护。
- 将“执行点击、服务器接受、成功钓获”分开记录，便于排查失败原因。
- 星露谷钓鱼从当前服务器资源包识别钓具与鱼获；换服重新学习，不沿用上一服结果。
- 普通与岩浆钓鱼使用钓点和 3×3 静止液体抛竿区域；岩浆需确认本服鱼竿能力，虚空使用独立站位与保存视角。
- 虚空模式可补珍珠、补经验，并将龙蛋与鞘翅分别存箱；只显示当前模式所需配置。
- 鱼获可选原地出售、箱子卸货或全丢；后勤任务依次执行，运行状态和结果可在模块详情核对。

### 种子挖矿与自动挖矿

1.0-beta3 首次正式随包发布种子挖矿：输入世界种子，本机独立计算进程离线推演矿物可能出现的位置；已加载区块会继续与真实方块对照。只有验证达到可靠条件后，预测目标才会交给自动挖矿。

1.0-beta4 加强假矿验证：远处伪装外观不算有效证据，必须近距离无遮挡复核；已验证候选优先就近选择，并修正可直走路线的成本。主世界钻石和下界远古残骸均在两条版本线的独立本地服实挖核对。

- 主世界支持钻石、红石、青金石、金、铁、铜、煤与绿宝石。
- 下界支持远古残骸、下界石英与下界金，并使用独立验证证据。
- 青色、绿色、灰色与琥珀色标记分别表达预测、确认、缺失与调度敏感。
- 自动挖矿负责到达目标、破坏矿物、切换下一颗，并处理战斗、食物、耐久与卸货。
- 预测只看种子，不读取你的世界；关闭功能时计算进程完全不启动。

## 不止四个模块

模块中心还包含 ID 识别与配置、自动箱子、原版自动农场、自动骨粉、自动附魔、村民交易、图书管理员、世界显示与 ESP 等功能。公开测试阶段会优先保证核心链路，再逐项扩大实机覆盖。

## 状态与隐私

在线名单不显示完整玩家名，本人账户区仍保留完整名称与头像。

主页保留正版状态、在线人数、用户排行、累计使用人数、网络地区、IP 与最后同步时间。后端只维护在线统计、公开排行所需的最小账号状态，以及玩家主动使用的管理员聊天；不收集玩家坐标、生命、服务器、模块开关、崩溃详情或指令记录。

IP 与网络地区由客户端在本机查询后直接展示，不写入 yiyiaddon 后端。管理员聊天仅用于玩家与维护者沟通。

## 安装

| 项目 | 要求 |
| :--- | :--- |
| Minecraft | **26.1.2** 或 **26.2**，两个安装包不能混用 |
| Fabric Loader | **0.19.5** 或更新兼容版本 |
| Fabric API | 26.1.2：`0.155.2+26.1.2`；26.2：`0.161.0+26.2` |
| Java | **25** |
| 系统 | 当前发布包提供 Windows x64 / ARM64 原生组件 |

1. 打开 [Releases](https://github.com/fxjcangku/yiyiaddon/releases/tag/v1.0-beta7)，下载文件名末尾与你游戏版本一致的 ZIP。
2. 解压 ZIP，把里面的 yiyiaddon JAR 与对应版本 Fabric API 一起放进实例的 `mods`。
3. 不要把 ZIP 直接放入 `mods`，也不要额外安装 Baritone；寻路组件已经随包提供。
4. 第一次运行建议使用独立实例，并先备份存档与配置。

## 版本状态

**1.0-beta7 · 公开测试版**

- **星露谷钓鱼**：新增虚空垂钓与补经验、分类卸货；完善岩浆能力识别，修复半砖通道、正常空杆误停、部分奖励漏识别与后台出售跳屏。
- **星露谷农场**：修复在线时长干扰季节识别；季节被隐藏时不沿用过期结果。
- **界面与操作**：启动自检支持连续设点；更新提醒按模块显示重点，完整说明单独打开。

完整变更见 [beta7 发布页](https://github.com/fxjcangku/yiyiaddon/releases/tag/v1.0-beta7)。配置与手动搬物方式见[功能指南](功能指南.md)。

本轮验证使用独立单机实例；原服务器测试已跳过，各服插件菜单、钓鱼与长时间挂机效果仍需实际反馈。

当前仅支持 26.1.2 与 26.2，26.3 及以后暂不支持。
