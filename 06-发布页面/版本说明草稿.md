**首个测试版** —— 独立开发的 Minecraft Fabric 客户端模组。

## 1. 下载

| 游戏版本 | 下载 | 配套 Fabric API |
| :--- | :--- | :--- |
| 26.1.2 | `yiyiaddon-1.0-beta1-26.1.2.zip` | `0.155.2+26.1.2` |
| 26.2 | `yiyiaddon-1.0-beta1-26.2.zip` | `0.161.0+26.2` |

## 2. 运行环境

Fabric Loader `0.19.5`+ / Java `25`。解压后放进 `mods`，别直接丢 ZIP；装错版本无法启动。内置寻路组件已随包提供，不用另装。

## 3. 更新日志

- 9 月 21 日：修复退出游戏后进程卡住十几秒、并被误报为「客户端崩溃」的问题。

## 4. 使用提醒

建议先用独立实例并备份存档；**26.3 及以后暂不支持**。
