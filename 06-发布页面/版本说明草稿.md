独立 Fabric 客户端模组：把种植、采掘、交易、后勤这些重复劳动接成能一直跑的流程。

## 支持范围

| 项目 | 要求 |
| :--- | :--- |
| 游戏 | Minecraft **26.x**（当前支持 **26.1.2** 与 **26.2**；**26.3 及以后暂不支持**） |
| 加载器 | Fabric Loader **0.19.5** 或更新兼容版本 |
| 依赖 | 与游戏版本对应的 Fabric API：26.1.2 用 `0.155.2+26.1.2`，26.2 用 `0.161.0+26.2` |
| Java | **25** |

## 下载与安装

**按你的游戏版本下对应那个包，装错会无法启动。**

| 游戏版本 | 下载 |
| :--- | :--- |
| 26.1.2 | `yiyiaddon-1.0-beta1-26.1.2.zip` |
| 26.2 | `yiyiaddon-1.0-beta1-26.2.zip` |

解压后，把里面的 JAR 和对应版本的 Fabric API 一起放进实例的 `mods` 文件夹，**不要直接把 ZIP 丢进去**。

## 本版内容

首个测试版，已接入的部分功能（完整说明见仓库首页）：

| 方向 | 模块 |
| :--- | :--- |
| 农场 | **星露谷农场**：识别服务器资源、分区与混种、作物配额、日常照料、种子与成品仓储 |
| 采集 | **自动挖矿**（寻路采掘、满载卸货、食物与工具补给）、**自动农场**、**自动骨粉** |
| 交易 | **自动附魔**、**自动村民交易**、**自动图书管理员** |
| 整理 | **ID 识别 / ID 配置**、**自动箱子**（多种工作方式与逐物品取物数量） |
| 显示 | **透视**、**水源显示**、**ESP 全局设置** |

## 更新日志

- **新增**：首个测试版，上面这些模块与统一的操作界面。
- **修复**：同一标签下先前的两个包进单人世界会立刻崩溃（秒破模块读到了未初始化的内部状态），已修复并重新上传。
  **版本号没变，游戏内不会提示更新 —— 之前下载过的请重新下载一次。**

## 已知问题

- 完整游戏内功能与长期性能仍在测试中，建议先用独立实例，并备份存档与配置。
- 星露谷农场、自动挖矿依赖对应服务器的资源包与传送指令配置，不承诺兼容所有自定义服务器。
- **26.3 及以后暂不支持。**
