**首个测试版** —— 面向 Minecraft Java 版 26.x 的独立 Fabric 客户端模组，主打星露谷农场、自动挖矿与 ID 联动自动箱子。

## 1. 下载

| 游戏版本 | 下载 | 配套 Fabric API |
| :--- | :--- | :--- |
| 26.1.2 | `yiyiaddon-1.0-beta1-26.1.2.zip` | `0.155.2+26.1.2` |
| 26.2 | `yiyiaddon-1.0-beta1-26.2.zip` | `0.161.0+26.2` |

## 2. 运行环境

- **加载器**：Fabric Loader `0.19.5` 及以上
- **运行环境**：Java `25`
- **安装方式**：解压后把 JAR 放入 `mods`，请勿直接放入 ZIP
- **版本对应**：包与游戏版本必须一致，装错版本无法启动
- **内置组件**：寻路组件已随包提供，无需另行安装
