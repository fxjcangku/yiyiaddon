构建命名规则：执行 `./gradlew buildPersonal`（或 `build`）生成个人版 `build/libs/yiyiaddon-1.0-beta1-personal+26.1.2.jar`，执行 `./gradlew buildBoth` 一次出两条版本线的个人版（末段 `+26.1.2` / `+26.2` 区分版本线）；执行 `./gradlew buildRelease` 生成混淆发布包 `build/release/yiyiaddon-1.0-beta1-26.1.2.jar` 与同名 ZIP。**两条线的版本号相同，个人版与发布版都靠 MC 版本后缀区分**。发布 JAR 仍经过混淆和保护检查，只取消「混淆」字样；ZIP 内仅包含该 JAR。版本号与 MC 版本随项目自动变化。发布包名也是游戏内更新提示的判据（`ReleaseCatalog`），个人版不会被当成可安装包。

2026-09-20 线上状态：`v1.0-beta1` 挂**两个带 MC 版本的 ZIP** —— `yiyiaddon-1.0-beta1-26.1.2.zip`（SHA-256 `909a1eec…`）与 `yiyiaddon-1.0-beta1-26.2.zip`（`0358db44…`），与本地文件逐一比对一致；旧的 `yiyiaddon-1.0-beta1.zip` 已删除。Release 正文、公开仓库首页与封面同步改为「26.x（26.1.2 / 26.2，26.3 及以后暂不支持）」（公开仓库提交 `28db4bf`）。对应映射备份 `773a2b43`（26.1.2）与 `1bcf30d9`（26.2）；同日先发过一版（`ef18ca55` / `1d82b502`），随后加上「更新提示按版本线筛附件」的修复并重出覆盖，旧摘要只作历史。**同标签换附件不改版本号，已装 beta1 的玩家不会收到更新提示**；要提示需递增版本号。

- `版本说明草稿.md`：已用于本次 Release 的正文源文件，后续修改需单独同步远程。
- `首页效果预览.png`：实际浏览器渲染的首页效果图。
- `工具/生成预览.mjs`：从两份 Markdown 生成预览，依赖 Node.js 与 marked，可指定已有模块的路径。

新版采用方块农场与矿洞场景、点阵标题、苔绿与木石配色，动效为代码控制的轻微光点、薄雾层与矿石高光。旧 SVG 封面保留作历史草稿，现行首页不引用。首页只使用 Markdown 与基础 HTML；预览页的物品栏风格侧栏、主题按钮和页面外框用于本地查看，不会作为 GitHub 页面控件发布。GitHub 的导航、按钮和页面布局由平台控制，不能通过 README 更改。

本地预览根据首页正文生成；后续修改 README 后需要重新生成预览，不能只改预览文件。远程 Release 已回读核对预发布状态和附件摘要；本地外框不等同 GitHub 实际皮肤。

```powershell
node "06-发布页面/工具/生成预览.mjs" "<现有 marked 模块的 marked.esm.js 完整路径>"
```

如果当前 Node 环境已能解析 `marked`，可以省略最后一个参数。生成工具仅写本地 HTML，不包含远程发布动作。**生成结果对 `marked` 版本敏感**：本次用 marked 12.x 生成，换版本会改动大量无关空行（9.x 也可）；重新生成后确认 diff 里只有你改的那几行。

支持范围口径：正文写 **26.x**（当前支持 26.1.2 与 26.2，26.3 及以后暂不支持），封面底栏同样写 `MINECRAFT 26.x`，「26.x」的具体范围只写在安装准备表里。改动这一口径要同时改 `仓库首页/README.md`、`版本说明草稿.md`、`工具/生成预览.mjs`（侧栏注释）与 `工具/制作动态封面.cjs`，再重跑上面两条生成命令。

`工具/制作动态封面.cjs` 接受已安装 playwright 和 sharp 的 node_modules 目录，使用本机 Edge 渲染动画帧并编码 GIF；`工具/预览样式.css` 管理本地预览样式。生成器不修改原始场景插画。

页面详细介绍星露谷农场、自动挖矿、自动箱子、自动农场、自动附魔、自动村民交易与自动图书管理员。两张专题插画是功能示意，不是实机截图。已检查 1440px 桌面、390px 窄屏、深浅主题、页内导航、折叠说明与版本说明切换。

本轮通过独立公开仓库检出提交首页、GIF、静态封面及两张专题图，共五个文件；没有推送主项目源码历史。Release 仅上传混淆 JAR 和校验文件。公开提交为 `2aabfc68161c046552b4f8457a8fa7f92fab094e`。源码、映射、测试归档和开发报告未公开。完整游戏功能仍需实际测试，Beta 不等于正式稳定版。

资料中的软件环境来自当前 gradle.properties、fabric.mod.json 和 build.gradle；功能范围来自 AddonModules 的实际注册。本轮不修改模组运行代码与许可文件。
