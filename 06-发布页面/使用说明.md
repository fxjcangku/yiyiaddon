# 发布页面设计稿

日期：2026-09-19

最新调整：Release 已精简为「yiyiaddon 1.0 · 首个测试版」及三段短说明；公开附件仅 `yiyiaddon-1.0-beta1.zip`，解压得到 `yiyiaddon-1.0-beta1.jar`。此前带 obfuscated 后缀的附件已移除。内部保护与映射不变，历史发布记录见报告 125，命名调整见报告 126。

用户后续授权公开 Beta，已发布 Minecraft 风格展示首页与 v1.0-beta1 混淆预发布版。
公开首页：https://github.com/fxjcangku/yiyiaddon
版本页面：https://github.com/fxjcangku/yiyiaddon/releases/tag/v1.0-beta1

- `页面预览.html`：打开即可查看首页的本地渲染，可切换深浅主题。
- `仓库首页/README.md`：供公开仓库使用的首页正文。
- `仓库首页/展示资源/方块世界封面.gif`：1120×520、40 帧、5 秒循环的 Minecraft 风格封面，约 411 KB。
- `仓库首页/展示资源/方块世界封面.png`：同版静态封面，供偏好静态图的读者查看。
- `仓库首页/展示资源/方块世界场景.png`：生成的场景插画源文件，仅保留本地，不冒充实机截图。
- `版本说明草稿.md`：已用于本次 Release 的正文源文件，后续修改需单独同步远程。
- `首页效果预览.png`：实际浏览器渲染的首页效果图。
- `工具/生成预览.mjs`：从两份 Markdown 生成预览，依赖 Node.js 与 marked，可指定已有模块的路径。

新版采用方块农场与矿洞场景、点阵标题、苔绿与木石配色，动效为代码控制的轻微光点、薄雾层与矿石高光。旧 SVG 封面保留作历史草稿，现行首页不引用。首页只使用 Markdown 与基础 HTML；预览页的物品栏风格侧栏、主题按钮和页面外框用于本地查看，不会作为 GitHub 页面控件发布。GitHub 的导航、按钮和页面布局由平台控制，不能通过 README 更改。

本地预览根据首页正文生成；后续修改 README 后需要重新生成预览，不能只改预览文件。远程 Release 已回读核对预发布状态和附件摘要；本地外框不等同 GitHub 实际皮肤。

```powershell
node "06-发布页面/工具/生成预览.mjs" "<现有 marked 模块的 marked.esm.js 完整路径>"
```

如果当前 Node 环境已能解析 `marked`，可以省略最后一个参数。生成工具仅写本地 HTML，不包含远程发布动作。

`工具/制作动态封面.cjs` 接受已安装 playwright 和 sharp 的 node_modules 目录，使用本机 Edge 渲染动画帧并编码 GIF；`工具/预览样式.css` 管理本地预览样式。生成器不修改原始场景插画。

页面详细介绍星露谷农场、自动挖矿、自动箱子、自动农场、自动附魔、自动村民交易与自动图书管理员。两张专题插画是功能示意，不是实机截图。已检查 1440px 桌面、390px 窄屏、深浅主题、页内导航、折叠说明与版本说明切换。

本轮通过独立公开仓库检出提交首页、GIF、静态封面及两张专题图，共五个文件；没有推送主项目源码历史。Release 仅上传混淆 JAR 和校验文件。公开提交为 `2aabfc68161c046552b4f8457a8fa7f92fab094e`。源码、映射、测试归档和开发报告未公开。完整游戏功能仍需实际测试，Beta 不等于正式稳定版。

资料中的软件环境来自当前 gradle.properties、fabric.mod.json 和 build.gradle；功能范围来自 AddonModules 的实际注册。本轮不修改模组运行代码与许可文件。
