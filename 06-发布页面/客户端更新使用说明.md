# 客户端版本与更新

日期：2026-09-19

首页右上角显示当前版本与发布类型，当前版本为 `v1.0-beta1 · 测试版`。版本信息来自安装的模组元数据。

- **项目仓库**：打开公开仓库首页。
- **检查更新**：手动读取发布列表，状态显示在版本旁边。有更新时弹出提示，手动检查可以查看已经跳过的版本。连续点击间隔至少 10 秒。
- **反馈问题**：打开 GitHub Issues 新建页面，自动填写当前插件版本、问题描述、复现步骤、预期结果、实际结果和截图或日志栏目。玩家自行补充并提交，提交后反馈出现在仓库 Issues；需要 GitHub 登录。不会自动采集或上传日志与账户数据。

客户端启动后在后台检查，之后每 15 分钟检查一次。只有更高版本、已经公开且上传了同名发布 ZIP 或 JAR 的 Release 才触发更新；修改仓库介绍或覆盖同一版本附件不会触发。Beta 测试版也参与检查，草稿与个人版附件不参与。

发现新版时，只在原版主菜单或插件主界面稳定后弹窗，不抢占游玩、容器和输入界面。断网、超时或接口限流时显示“暂时无法检查”，游戏仍可继续使用。

- **立即更新**：用系统浏览器打开对应版本发布页。下载并手动替换模组后重启客户端，不会热替换运行中的 JAR。
- **稍后更新**：本次客户端运行期间不再自动提示，重启后重新检查。返回键与 Esc 同样关闭本次提醒。
- **跳过此版本**：将所选版本写入 `config/yiyiaddon/update.json`，重启后也不自动提示该版本；发布更高版本后恢复提醒。保存失败时显示错误，保留弹窗供重试。

发布时递增 `gradle.properties` 中的版本号，创建相应版本标签并上传 `yiyiaddon-<版本>.zip` 或 `.jar`。当前客户端读取最近 100 条发布记录，按版本值判断新旧；例如 `1.0-beta10` 晚于 `1.0-beta2`，`1.0` 晚于同一版本的 Beta。

此功能在本地完成后，需要将包含它的新构建发布并安装，旧 JAR 不会自行获得更新检测能力。
