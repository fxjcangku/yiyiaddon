- **新增** 整图与分区预览显示已铺 待铺和剩余数量 正确地毯保留 错色自动纠正 逐格进度按服务器 维度和投影保存

- **优化** 按投影实际颜色显示地毯箱 连续点位引导列出缺项 双箱统一轮廓 西北角选点显示范围 坐标和地毯高度

**电脑通用包** 面向 Windows x64 与 Mac 系统 ARM64 Mac 使用原生 ARM64 Java 每个游戏版本分别安装对应的 `desktop` JAR

Intel Mac 不在本次支持范围 Windows ARM64 Linux 与 Android 同样不在此次电脑通用包的支持范围

当前没有可下载的 1.3 附件 [查看现有 1.2 正式版](https://github.com/fxjcangku/yiyiaddon/releases/latest) 其中无平台后缀的历史包仅适用于 Windows x64

> [!IMPORTANT]
> **已内置经过调教优化的 Baritone 请卸载自行安装的 Baritone 避免重复加载或冲突**

1. 正式附件提供后 先核对 Minecraft 版本与平台 Windows x64 和 Mac 选对应游戏版本的 desktop JAR
2. 退出游戏 将对应 JAR 与匹配的 Fabric API 放入同一实例的 mods 文件夹 移出旧版或重复的 yiyiaddon
3. 已内置经过调教优化的 Baritone 请卸载自行安装的 Baritone 避免重复加载或冲突
4. Fabric Loader 使用 0.19.5 或以上 Mac 使用原生 ARM64 Java 1.21.11 选 Java 21 26 系列选 Java 25
5. 启动后默认按 G 打开界面 地图画需自备地毯机 地毯与制图平台 再导入投影并完成点位配置

## 兼容与运行

- 地图画已有受控单人施工 真实补货 断点续作 成图与制图台锁图记录 不同场次的速度与耗时分别计算
- 26.2 密集农场受控场完成 576 株采收和实际入桶 并核对材料与回执
- Mac 已完成 ARM64 原生启动及 26.2 通用候选的主题 缩放 保存与世界重入验证
- 四个游戏版本完成各自对应的编译与组装检查 实机结果按具体版本 系统和场景记录

## 使用边界

- 地图画处理单张 128×128 平面原版地毯投影 需要自备底板 地毯机和施工材料
- 制图台锁图为可选功能 需绑定原版制图台 并在地图用品箱准备空地图与普通透明玻璃板
- 自动驱魔使用前学习本服菜单 星露谷功能使用本服资源包与实际物品配置
- 实际放置 采收 容器 飞行与矿物预测仍受服务器权限 地形生成规则 触距 网络和限速影响
- 宣传封面为功能概念图 desktop 安装包尚未上传
