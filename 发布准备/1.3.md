# yiyiaddon 1.3 发布准备

**全自动地图画 与 Mac 原生适配**

全自动地图画完成从投影导入 按需补给 连续铺设 到成图锁定的任务衔接 同步加入 Apple Silicon Mac 原生适配 并完善星露谷农场 自动附魔 聊天与运行反馈

**本页为发布准备 新安装包尚未上传** 当前公开正式版仍为 1.2 本页不替换正式下载与历史附件

[官网阅读](https://www.yiyiaddon.asia/release.html?prepare=1.3) · [下载与安装](#下载与安装) · [更新记录](#详细更新记录) · [验证进度](#验证进度) · [反馈问题](https://www.yiyiaddon.asia/feedback)

## 下载与安装

Minecraft **1.21.11 / 26.1.2 / 26.2 / 26.3** 各自使用对应的 JAR

| 游戏版本 | 1.3 安装包 | Java | Fabric API |
| --- | --- | --- | --- |
| 1.21.11 | 等待正式附件上传 | 21 | `0.141.6+1.21.11` |
| 26.1.2 | 等待正式附件上传 | 25 | `0.155.2+26.1.2` |
| 26.2 | 等待正式附件上传 | 25 | `0.161.0+26.2` |
| 26.3 | 等待正式附件上传 | 25 | `0.164.0+26.3` |

**电脑通用包** 面向 Windows x64 与 Apple Silicon macOS ARM64 Mac 使用原生 ARM64 Java 每个游戏版本分别安装对应的 `desktop` JAR

Intel Mac 不在本次支持范围 Windows ARM64 Linux 与 Android 同样不在此次电脑通用包的支持范围

当前没有可下载的 1.3 附件 [查看现有 1.2 正式版](https://github.com/fxjcangku/yiyiaddon/releases/latest) 其中无平台后缀的历史包仅适用于 Windows x64

> [!IMPORTANT]
> **已内置经过调教优化的 Baritone 请卸载自行安装的 Baritone 避免重复加载或冲突**

1. 正式附件提供后 先核对 Minecraft 版本与平台 Windows x64 和 Apple Silicon Mac 选对应游戏版本的 desktop JAR
2. 退出游戏 将对应 JAR 与匹配的 Fabric API 放入同一实例的 mods 文件夹 移出旧版或重复的 yiyiaddon
3. 已内置经过调教优化的 Baritone 请卸载自行安装的 Baritone 避免重复加载或冲突
4. Fabric Loader 使用 0.19.5 或以上 Mac 使用原生 ARM64 Java 1.21.11 选 Java 21 26 系列选 Java 25
5. 启动后默认按 G 打开界面 地图画需自备地毯机 地毯与制图平台 再导入投影并完成点位配置

[详细安装指南](https://github.com/fxjcangku/yiyiaddon/blob/master/安装指南.md) · [平台与版本要求](https://github.com/fxjcangku/yiyiaddon/blob/master/版本说明.md)

## 本次亮点

| 功能 | 本次变化 |
| --- | --- |
| **全自动地图画** | 导入投影后沿中线连续铺设 自动换色 按需补货与断点续作 完成后生成地图 可选制图台锁图 |

## 详细更新记录

<details>
<summary><strong>全自动地图画</strong></summary>

- **新增** 支持单张 128×128 的平面 16 色原版地毯地图画 可导入 NBT Litematic 与 Sponge Schem 投影 导入失败保留原任务
- **新增** 按西北角与施工中线往返推进 人物移动时自动换色并连续铺设多格 默认覆盖左右各六排 尾带按实际宽度完成
- **新增** 补货按接下来连续区域的剩余需求计算 扣除已有库存与正确格 充分使用有效背包空间 返回原施工前沿继续
- **新增** 提供步行 飞行绕过 原版飞行三种施工方式与四档速度 默认极速 原版飞行需要服务器授予权限
- **优化** 暂停 重连和异常恢复保留逐格进度 提供整图与分区预览 自动纠错和清空施工进度入口
- **优化** 替换投影后重新统计用料 解绑不再需要的颜色箱 保留仍需颜色箱 食物箱 地图用品箱与制图台点位
- **新增** 完整地毯与地图像素确认后完成成图 可选制图台自动锁图 按需领取一张空地图与一片普通透明玻璃板
- **新增** HUD 分别显示本张总耗时 铺设 补给赶路与成图收尾 暂停和离线停表 完成后冻结
- **修复** 完善联机回执超时后的安全收尾和继续任务 聊天 好友 全屏地图等正常界面打开时仍可继续后台施工

</details>

<details>
<summary><strong>Windows 与 Apple Silicon Mac</strong></summary>

- **新增** desktop 通用电脑包同时包含 Windows x64 与 Apple Silicon macOS ARM64 所需原生依赖 四个 Minecraft 版本分别安装对应包
- **优化** 按真实系统与 Java 进程架构选择依赖 更新检查只接受匹配本机的平台附件 历史 Windows 包不会误推给 Mac
- **修复** 修复 Mac 字体处理的空字形边界及紧凑自检弹窗的命令方块图标显示 完善缩放与世界重入后的图标恢复
- **说明** 本轮先完成页面与文案准备 desktop 安装包尚未上传 当前公开 1.2 无平台后缀附件仍为 Windows x64 包

</details>

<details>
<summary><strong>星露谷农场</strong></summary>

- **优化** 每轮按区域顺序完成本区浇水 锄地与种植 全部区域准备后再逐区采收 补水 补种补给和卸货后接回未完任务
- **优化** 播种 锄地与成熟采收复用连续多目标交互 窄田按实际触距沿中线完成 更宽田区分带推进 保留服务端额度与回执确认
- **优化** 减少密集成熟田中的重复资源读取 重扫和逐株转头 采收与产物统计按实际变化确认
- **优化** 顺序浇水并逐格确认干湿 跳过已湿位置 多区分别优先查找本区附近可用静水 单区沿绑定水源补水
- **新增** 农场方案可命名 按需新建与删除 作物 田区 配额 种子箱 品质箱和补水点按方案保存
- **新增** 混种田独立设置作物配额与顺序 按确认品种记住格位 缺种时保留本品种需求 不用其他种子顶替
- **修复** 修复播种回执等待造成的停顿 已完成边线空跑 提前换区 缺种原因被等待生长覆盖 及空壶维护反复重进
- **优化** 补齐作物与物资中文名称 种子和产物双图 调整种子补给与卸货入口 作物详情按 Esc 逐级返回
- **新增** 没有可执行农活与后勤时返回启用田区的共同中心 在安全范围内短走 发现新农活后重新调度

</details>

- **优化** 公共地面寻路统一移速与靠站制动 收到有效位置纠正后逐档降速并等待稳定 避免多模块重复叠加

- 26.2 密集农场受控场完成 576 株采收和实际入桶 并检查材料与回执 该结果不等于原服帧率或所有插件环境的验收
- Mac 已完成 ARM64 原生启动及 26.2 最终通用候选在独立 Fabric 加测试夹具环境的主题 缩放 保存与世界重入验证
- 四个游戏版本分别完成编译与组装等对应检查 其他版本及 Windows 的本轮同包实机范围按实际记录保留 未宣称四版双端全部通过
- 服务器插件规则 原服完整农场与驱魔流程 飞行纠正 管理员检测重连及长期挂机仍需继续复测

实际范围按游戏版本 系统和场景分别说明 开发启动 最终安装包验证与用户原服验证不互相替代

## 使用边界

- 地图画只处理单张 128×128 平面原版地毯投影 不自动建底板 地毯机或清除普通障碍
- 制图台锁图为可选功能 需要绑定原版制图台并在地图用品箱准备空地图与普通透明玻璃板
- 实际放置 采收 容器与飞行仍受服务器权限 触距 网络和限速影响 请遵守所在服务器规则
- 种子挖矿的矿物精度和部分服务器兼容仍有待处理事项 本次不宣称误报漏报全部修复
- 宣传封面是功能概念图 页面准备完成不代表安装包已经公开发布
