## 四、遇到的问题

`wrangler d1 list`、`wrangler deployments list` 两个查询命令失败，报错分别为
`The request to Cloudflare's API timed out` 与 `fetch failed`，并伴随 Node 的 libuv 断言退出。

排查结论：

- PowerShell 直连 `https://api.cloudflare.com/client/v4/user/tokens/verify` 返回 HTTP 200；
- Node 侧 `fetch` 同一地址同样返回 200，Token 有效；
- Node 解析 `api.cloudflare.com` 得到 `198.18.0.189`，属于本机代理软件的 fake-IP 网段。

即本机网络经过本地代理，部分 API 子请求被丢弃或超时。该问题只影响查询类命令，
`wrangler deploy` 本身正常完成。后续遇到同类报错，重试即可；仍失败时可改用 Cloudflare 控制台操作。
