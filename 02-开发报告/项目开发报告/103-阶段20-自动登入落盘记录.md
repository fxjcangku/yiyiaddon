## 5 有意差异与「登记不搬」（逐条给理由）

1. **第三方「流星自带 AutoReconnect」接管逻辑不搬**（旧 728-729 起：断线时关闭它并播报
   `§e已自动关闭流星自带【自动重连】，本模块将接管重连。`）。本项目**不依赖任何第三方客户端框架**
   （第 32 / 43 条），没有对应物，本模块只负责自己的重连。已在 `AutoLoginModule` 类注释登记，
   **提请用户拍板是否需要为第三方接管行为补一条等价说明**。
2. **旧 `notify` 覆写里的 `"自动登入："` 前缀裁剪不搬**：旧项目全树无任何调用点会传入带该前缀的消息
   （`grep` 只命中判断本身），属旧遗留死代码（第 26 条口径）。
3. **`onReceiveMessage` 首行 `contains("[Jeraddon]")` 自播过滤不搬**（旧 594）：旧项目自身播报前缀为
   `[yiyiaddon]`，该判断永不命中；且本项目播报走本地 `sendSystemMessage`，不会回灌成服务器文本事件。
4. **旧 `onGameLeft` 为空实现** → 不声明 `DISCONNECT` 订阅；断线处理照旧全部由断线界面触发。
5. **旧设置 `隐藏断线页按钮`（`hideReconnectButton`）不搬**：旧项目全树只有声明、无任何使用点（死代码）。
6. **`getReconnectHandler` / `getCfg` 等旧访问器不搬**：无外部消费者。
7. **`leyuanStageChanged` / `leyuanHotbarSnapshot` 不搬**：旧实现无调用点。
8. **重连倒计时改承载**：旧 `getWidget` 只在 `RECONNECT_WAIT` 时显示倒计时表；新概览页**常驻**显示
   「§7重连状态：…」，非重连期给一句灰字说明（不给空白面板）。
9. **两个重连按钮加禁用态**：旧实现在非重连期点击无任何反应（悬案）；新按第 214 条 `disabledWhen`
   表明「当前没有可取消 / 可提前的连接调度」，判据与动作读同一份数据。
10. **`每步等待（tick）` 同名键**：旧「进服路线 · 通用子服」与「自用配置」各有一项，**名字完全相同**；
    旧框架设置是扁平名字表，同名两项实际共用同一个落盘键。本项目按 1:1 口径保留同一行为
    （`menuActionDelay` 与 `leyuanStepDelay` 读写同一个键），只登记不修改（见 `AutoLoginTexts` /
    `AutoLoginSettings` 类注释）。**这是旧实现的既有缺陷（两行互相覆盖），未自行改**，待用户决定是否收口。
11. **`进入方式` 与自用配置分两页**：旧「进服路线」组内 35 项单页过长，按旧源码分节标题拆为
    「进服路线」（通用子服 13 项）与「自用配置」（22 项）两页，名称逐字取自旧源码分节，不新造分类（第 183 条）。
12. **自用配置页在条件不满足时给一句灰字说明**：旧 `visible(...)` 会整组隐藏，新页若整组隐藏会只剩一个
    空折叠块，故加一句非设置项的提示（`  §8当前「进入方式」不是「自用配置」，本组设置暂不适用`）。
13. **概览页为新增只读页**：旧项目没有概览页；本页不含任何新设置项，只把旧 `getInfoString` 的 HUD 串、
    旧 `getWidget` 的两个按钮与旧设置的伪按钮集中展示（第 163 条：不新增面板动作）。

## 6 实机验证项

1. 模块中心「自动化」下出现「自动登入」，入口 + 内嵌说明（**无说明按钮**）；说明六章逐字。
2. 离线验证服：进服 → `你已进入登录大厅，正在检测登录状态。` → 世界加载等待 → `开始监听认证提示...`。
3. 服务器发登录提示 → `正在自动登录...` → 密码正确时回到就绪；注册提示走注册分支；
   密码未设置时提示 `登录密码未设置，跳过自动登录`。
4. 两小时免登录服：开「服务器免登录检测」→ 命中成功消息时关自动登录并进就绪；
   收到登录提示时自动关免检测并开自动登录（两条播报逐字）。
5. 单人世界 / 正版验证服：开模块即自动关闭并播报 `§c§l单人世界或正版验证服务器无需自动登录，模块已自动关闭。`
6. 互斥开关：开自动登录 → 自动注册被关 + 播报；反向再验一次；`检测服务器子服` 开 / 关各一条播报。
7. 通用子服路线（菜单传送 / 子服网络）：菜单工具识别 → 按点击顺序点击 → 侧边栏命中目标关键词 →
   `已确认到达目标区域（…）。` → 到达稳定等待后执行目标区域指令。
8. 自用配置路线：登录服按钮 → 欢迎页（书本直达主城 / 自用入口两档）→ 侧边栏确认主城 →
   世界传送 → 资源大区 → 资源二区 → 到达确认；主城钟兜底（Shift＋F）各验一次。
9. 挂机区回服：命中挂机区关键词 → 按 `挂机区菜单延迟（分钟）` 等待 → 返回主城大区 → 四步回服；
   「挂机区自动回服」关掉后不再触发。
10. 断线：`服务器断开，N 秒后重新连接。` → 概览页倒计时逐秒走 → 到点自动连接；
    `立即重连` 跳过倒计时；`§c停止重连` 取消并播报 `§c已停止自动重连。`；
    重连等待期手动回主菜单 → `§e已检测到手动返回主菜单，自动重连已取消。`
11. 自用路线异常恢复：断线后按 `异常恢复初始重试（秒）` 退避重连，超过 `异常恢复等待上限（分钟）`
    则当前步骤失败并停止。
12. 持久化（第 172 条）：改开关 / 数字 / 名单 / 两个物品 / 密码 → 完全关客户端重开 → 值仍为改后值；
    **密码重开后仍能自动登录**（打码显示、明文只在落盘文件里）。
13. 控制台：七个页签逐一切换、ESC 回模块页、底部刷新 / 关闭、状态条每秒刷新；
    概览页整页每秒重画且**鼠标按住时不重建**；其余页每秒只换状态条（输入框不被抹掉）。
14. 两个物品选择器：带图标、分组可折叠、点任意一行即选中；未选择时行显示 `未选择` 且无图标。
15. 八个名单：添加（去空白、重复跳过）、逐项移除、空态灰字；改完重启仍在。
