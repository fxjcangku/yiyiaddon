# 免费混淆构建与映射备份

日期：2026-09-19

## 本次目标与边界

用户要求为当前项目构建免费混淆 JAR，提高逆向成本，并明确要求新建 `05-混淆文件备份` 保存映射。
本次只改当前独立 Fabric 项目的构建流程；旧项目 `D:/mcaddon/26.1.2` 未修改，也未引入旧项目框架。
开始工作时源码工作区已有大量未提交修改，本次未回滚、提交或推送这些修改。

当前交付为 ProGuard 名称混淆与调试信息清理的可重复构建基线。
**未实现字符串加密、控制流混淆、虚拟化或本地代码保护，未达到可证明的“免费最高级别”；不保证无法反编译。**
没有把“不裁剪、不优化”描述为最强保护：这两项关闭是为了保留 Mixin 与反射路径的现有行为。

## 修改前证据

- `build.gradle` 原先仅有 Loom、编译与资源处理，未配置混淆任务。
- `src/main/resources/fabric.mod.json` 按名称加载 `YiyiAddon`、`YiyiAddonClient` 和两份 Mixin 配置。
- `feature/enchant/gear/GearEnchantData.java:62-101` 的四个嵌套 DTO 存在未注解的 JSON 字段。
- `feature/enchant/vanilla/VanillaEnchantDatabase.java:82-144` 的 Gson 中间模型同样存在按名称读取的字段。
- 多处配置以枚举 `valueOf` 还原设置，因此保留枚举常量与反射入口。
- 第三方 Baritone、Skija 以嵌套 JAR 随包分发，只处理自有 class，不改第三方 JAR。

## 实际改动

1. `build.gradle` 引用 `gradle/obfuscation.gradle`。
2. `gradle/proguard-rules.pro`：保留 Fabric 入口、Mixin、Gson 字段、枚举与 JNI 契约；
   混淆其余类、包、方法、字段名称，开启成员重载混淆；移除源码位置、行号和局部变量调试属性。
3. `gradle/obfuscation.gradle`：仅构建期引入 ProGuard 7.9.1；从实际工具链和编译依赖生成 libraryjars；
   处理普通 JAR 中的 class，再原样合入资源与嵌套依赖，形成独立发布包。
4. 发布检查：入口与 Mixin 存在、资源逐字节一致、禁止源码及映射混入、禁止临时埋点残留、
   确认确实发生重命名；隔离加载器检查全部 class 的成员签名，六组 Gson DTO 完成字段往返。
5. `05-混淆文件备份`：按版本和完整 JAR SHA-256 保存 `mapping.txt`、规则与产物信息；
   相同内容复用，不同内容拒绝覆盖。目录位于 `build` 外，不受 Gradle clean 影响。
6. 使用说明写入该目录的 `README.md`，与当前任务名、路径和实际能力核对一致。
   本次没有修改游戏界面、指令或模块帮助正文。

## 构建与使用

```powershell
.\gradlew build --console=plain -q
.\gradlew buildRelease --console=plain
```

普通 `build` 仍输出开发用的未混淆 JAR；对外分发必须选择 `buildRelease` 通过检查后的产物：

`build/release/yiyiaddon-1.0-beta1-obfuscated.jar`

映射中间文件位于 `build/obfuscation/mapping.txt`，长期备份位于：

`05-混淆文件备份/1.0-beta1/01-基础混淆版-21413309/`

映射、规则与内部报告不得作为公开 Release 附件。没有执行任何远程发布。
删除行号后仍可通过映射还原类和成员名称，但无法恢复精确源码行号。

## 方案依据与限制

[ProGuard 官方版本记录](https://www.guardsquare.com/manual/releasenotes) 表明 7.8 起支持 Java 25；
本次实际使用 7.9.1，并成功解析项目工具链及依赖。
[官方配置说明](https://www.guardsquare.com/manual/configuration/usage) 是名称与属性保留规则的依据。
另核查了 [Skidfuscator 社区版](https://github.com/skidfuscatordev/skidfuscator-java-obfuscator)，
其提供更强的流程和字符串变换，但本次未证明它在本项目 Java 25 依赖与 Fabric 环境中的兼容性，未接入。
“名称已经难读”不等于算法不可还原，名称混淆不能替代字符串和控制流保护。
