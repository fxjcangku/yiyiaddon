### 6.6 实体候选剔除「非生物」（用户 2026-09-18 追加，A 方案）

用户原话：「实体选择器是不是跟杀截一样的 我不想要宠物蛋」→ 选 A。

**先取证（第 167 条）**：查 `KillAuraTargetingPage:330-411` 的 `EntityEntry#drawIcon` 四级回退 ——
① 生物（非 `MISC`）走**实体模型渲染**；② 模型渲不出来的（玩家 / 投射物 / 标记）与非生物（船 / 矿车 /
盔甲架 / 展示框 / 画 / TNT）走刷怪蛋或同名物品图标；③ 静态物品兜底；④ 首字占位。
即：**「蛋」只出现在非生物与无模型实体上**，生物早就是实体模型图。

**改动**：`ui/VisionSelectors.java` —— 新增实体候选过滤（保留 `MobCategory != MISC` 的全部生物 +
玩家；其余剔除），并把名单状态文字的总数改为过滤后的候选数（与列表实际行数一致）。

| 项 | 内容 |
| --- | --- |
| 影响面 | **只影响透视模块的候选视图**；杀戮光环的候选表、图标实现、分组一行未改，也未复制第二份条目实现（第 169 条） |
| 代价 | 以后若要透视掉落物 / 船 / 矿车这类非生物，需要再放回来（属独立小改） |
| 编译 | `compileJava` **EXIT=0** |
| 待实机 | 候选里不应出现刷怪蛋图标（生物一律实体模型图）；不应出现船 / 竹筏 / 矿车 / 盔甲架 / 展示框 / 画 / TNT 等非生物行；玩家仍在列表里 |
