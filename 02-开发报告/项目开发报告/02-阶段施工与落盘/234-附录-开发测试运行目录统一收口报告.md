## 7. 发现并修正的真问题：测试任务借用开发者客户端目录

现象（开发者反馈）：`d:\mcaddon\yiyiaddon\run-26.1.2` 启动的「根本不是我的客户端」。

定位：`clientSeedVisualShaderTest`（⑬ 光影目视验收）是全仓库**唯一**仍把 `runDir` 指向 `run-${minecraft_version}` 的自动化任务，且注入 `yiyiaddon.seedpoc.enabled=1` / `seedpoc.visual=1` / `seedpoc.exit=1` 与 `--quickPlayMultiplayer 127.0.0.1:25565`。

实机证据（`run-26.1.2/logs/latest.log`，2026-09-23）：

```
[17:59:57] (FabricLoader) Loading 295 mods:              ← 开发者的真实环境
[18:00:17] (Minecraft) Setting user: yiyijia
[18:00:17] (yiyiaddon/seedpoc) 种子挖矿PoC：开发期实验已挂载……（系统属性 yiyiaddon.seedpoc.enabled=1）
[18:00:26] (yiyiaddon/seedpoc) 234目视验收：开跑 —— 种子 20260922 / 范围 3 ……
```

同一次运行改写了该目录的 `options.txt`（18:00）、`servers.dat`（18:00）、`config`（18:02）。即：跑这个任务时，开发者的开发客户端被替换成了一套自动验收装置（自动连服、自动传送、自动开面板、自动退出）。

修正：`clientSeedVisualShaderTest` 的 `runDir` 改为 `.dev-runs/${minecraft_version}/seed/visual-shader`，并写入注释说明该场景需要真实环境时由人手动把 `run-26.1.2` 的 `mods` / `shaderpacks` / `config` **只读复制**进测试目录，绝不回写日常目录。至此 `build.gradle` 中除 `client` 外再无任何任务引用 `run-<MC 版本>`。
