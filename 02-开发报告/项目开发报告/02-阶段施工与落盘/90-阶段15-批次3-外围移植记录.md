## 6. 修改内容（相对旧项目的全部改动）

1. **设置载体重写**：旧 12 个 `Setting` 对象 → 一个 `LibrarianSettings`（12 字段 + 5 组访问器 + `load/save`），键名逐字用旧设置名；数值 `load` 时收拢回取值域；旧项目只声明下界的五项按界面域收口（D-15-10）。
2. **模块入口重写**：只保留「事件订阅 + 参数装配 + 播报 + 自检」四件事；旧入口里的框架生命周期、自检播报、开关播报全部交给运行时（`ModuleManager`）。
   - `suppressEnableAnnounce() = true`：启动报告即本次启用的完整结论，不再叠一条运行时的「已开启」（等价旧 {@code chatFeedback = false} 对框架播报的抑制）；
   - 关闭不自己播「已关闭」：运行时 `ModuleManager.disable` 播的就是同一条 `§c§l已关闭`；
   - 暂停键按下播 `§c§l已强制结束` 后用 `setEnabledSilently` 关闭（否则同一次状态变化会出现两条提示）。
3. **D5 播报口径落地**：编排器四通道（`state` / `info` / `debug` / `error`）→ 标点清理 → 统一前缀；启动报告与「已强制结束」走 `notifyRaw`（不经清理，等价旧 `notify` / `notifyError` 通道）；`error` 保留 2000 ms 同文案节流；`state` 保留 7 条进度播报与去重。
4. **D4 控制台三页签**：概览（7 行只读实况：状态 / 目标附魔 / 半径 / 价格 / 命中策略 / 背包 / 自检）、设置（目标 / 行为 / 通知 / 调试 四折叠组 + 快捷键行末置）、日志（容量 80 流水）。顶栏走 `ConsoleHeaderBar`（第 216 条），消息说明行照旧在标题下（第 217 条）。
5. **D3 目标附魔选择器**：候选 = `level.registryAccess().lookupOrThrow(ENCHANTMENT).registryKeySet()`（含模组附魔），键 = 带命名空间的完整 ID（命中判据要求）；按 8 家族 + 兜底「其他」分组；`onAdd` 二次校验；加减即整表写回 + 立即落盘。
6. **通知组可见性 1:1**：「提示音」关闭时「附魔成功音效」行整行不铺（旧 `visible(playNotificationSound::get)`），开关带 `scheduleReload()`。
7. **状态摘要统一**：模块页与控制台状态条共用 `AutoLibrarianModule#statusSummary()` 与 `countItem(Item)`，不各拼一份（第 169 条）。
8. **图标验真**（第 140 条）：`\uE666` = Material Symbols Rounded 的 `auto_stories`（翻开的书）。验真方式为本机实测：`java.awt.Font.createFont` 加载本模组打包字体 → `canDisplay(0xE666) == true` → 渲染 PNG 目视确认为翻开书本且非豆腐块；同时确认本项目既有模块图标（E798 / E8B8 / E8B6 / E8F4 / E65F / E25B / E002 / EA79 / E1A1 / EF3D / EA12 / E663）无一占用该码点。
9. **未新增任何功能**：无指令、无点位、无 ESP、无新设置项、无新文案；界面元素全部来自既有壳件（第 163/171 条）。

### 9.2 必须让用户知道的旧行为（实机验收重点）

1. **播报会被抹标点**：`clean()` 正则抹掉 ASCII 标点与一批中文标点，因此玩家看到的正文<b>没有逗号、句号、冒号，`Lv.1` 会变成 `Lv1`</b>。这是旧项目原样（D5 拍板保留），不是本项目引入的排版事故；验收时不要当成 bug 修（要改必须用户点名）。
2. **「找到目标附魔」不发音**：设置描述写「找到目标和完成目标时播放提示音」，实际只有 `COMPLETE_TARGET` / `FINISH` 两个状态映射到 `SUCCESS` 才发音（D8 拍板照搬）。
3. **快捷键描述与行为不一致**：描述「切换暂停/继续，保留进度」，实际按下即强制结束并关模块（D2 拍板照实现，描述逐字留在 tooltip）。
4. **静默容器放行背包与创造背包**：运行中按 E 能正常开背包；被取消的只有箱子 / 交易等容器屏。
