## 3 框架适配（旧 → 新）

1. `GameJoinedEvent` / `GameLeftEvent` → `JOIN_SERVER` / `DISCONNECT`。
2. `PacketEvent.Receive` 读 `ClientboundCustomPayloadPacket` → 订阅 `SERVER_CHANNEL`（载荷即频道 id）。
3. `PacketEvent.Receive` 读 `ClientboundCommandsPacket` → 订阅 `PACKET_RECEIVE` 按类名等值判定；指令树在检测时直读 `connection.getCommands()`。
4. 总线 `RubberBandDetectedEvent` → `TacticalCoordinator.addListener`（启用注册 / 关闭注销）。
5. 会话代次：旧协调器靠 `priority=-1000` 抢先推进；本项目改为进服首次调度推迟一帧，避免冻到上一会话（订阅顺序不保证）。
6. 单人世界静默关闭 → `ModuleManager.setEnabledSilently`。
7. `handleResourcePackPushFromVanilla(packet, sendPacket)` → `handleResourcePackPush(UUID, String, String)`（模块拿不到包对象）。
8. `ResourcePackDownloader` → `ResourcePackCache`（同源件）。
9. 旧基类 `notify/warning/notifyError/highlight*` → 本类内同名同色码包装 + `ClientChat.send`。
10. `getWidget` 双按钮 + `HelpScreen` → 模块页入口 + 内嵌说明。

## 5 拍板结论与落地（2026-09-18 用户同意）

| # | 事项 | 结论 | 落地 |
| --- | --- | --- | --- |
| 1 | 资源包接管接线 | **接** | 新增 core 层闸门 [ResourcePackGate.java](file:///d:/mcaddon/yiyiaddon/src/main/java/com/yiyiaddon/core/resourcepack/ResourcePackGate.java)（Mixin 只依赖 core，不反向依赖业务模块）；[ResourcePackPushMixin](file:///d:/mcaddon/yiyiaddon/src/main/java/com/yiyiaddon/mixin/client/ResourcePackPushMixin.java) 改 `cancellable = true` + HEAD 询问闸门，返回 true 则 `ci.cancel()`；模块 `onEnable` 注册 / `onDisable` 注销 |
| 2 | `§b查看下载资源包` 落位 | 保持现状（控制台「资源包劫持」页） | 无需改动 |
| 3 | 枚举落盘格式 | 中文显示名 | 现状即此 |
| 4 | 说明措辞 | 接线后能力已真实生效 | **不需要改措辞** |
| 5 | 下载提示前缀 `[服务器核心]` | 接受 | 无需改动 |

**接线设计说明**：旧项目由 Mixin 直接调用模块入口（`handleResourcePackPushFromVanilla`），新项目若照抄会让 Mixin 反向依赖 `feature` 包。故在 core 层加一个可注册/注销的闸门：模块把自己的处理器注册进来，Mixin 只问「要不要取消原版流程」。`ResourcePackGate.handle` 内部吞异常并退回原版（接管失败不能让玩家卡在资源包界面）。判定发生在 HEAD（可能仍在网络线程），处理器只做「读设置 + 发响应包（`Connection.send` 线程安全）+ 异步提示」，不触碰世界与界面。

## 6 实机验证项

1. 单人世界：仅 `§c单人世界无需检测`，模块自动关闭、无「已开启」播报。
2. 多人服：`已在服务器中，将在 3 秒后开始侦测` → 3 秒后出报告（多行块 / `§8▸` 对齐 / 风险等级行）。
3. 换服、断线不残留；跨服迟到结果被协调器丢弃。
4. Paper 系 → `Paper（指令树）`；GrimAC 服 → `GrimAC（插件频道）`（多命中以 ` + ` 连接）。
5. 无静态指纹服：3 次拉回后复核并显示 `未知反作弊（拉回频繁，已确认存在移动校验）`。
6. 控制台 3 页签、概览每秒重画、其余页只换状态条、悬停显示旧描述原文。
7. 落盘：`侦测延迟（秒）=5` → 完全重启 → 仍为 5。
8. 显隐：切 `自动白嫖` → 重试次数 / 读取超时 / 断点续传三行出现；切回消失。
9. `§b查看下载资源包` → 打开 `yiyiaddon_resourcepacks`；异常播报 `打开资源库失败：…`。
10. 接线后：暴力绕过应回 ACCEPTED + SUCCESSFULLY_LOADED 并拦截原版；自动白嫖放行原版并旁路落盘。
11. `runClient` 启动无崩溃、日志含 `yiyiaddon initialised`。
