## 4. 分类调整说明

- **`InventoryOps`（task 包内，包私有）**：旧任务层对旧框架背包工具（`InvUtils.find / findInHotbar / swap / swapBack / move().toOffhand() / move().to(槽)`）的调用点分散在 4 个任务类。按第 34 条（框架层必须按本项目架构重写）收敛为本模块唯一一份原语：查找直接遍历 `Inventory`；副手交换走 `ContainerInput.SWAP`（button=40，快捷栏 0~8 映射菜单槽 36~44，与 `MiningStateMachine.swapWithOffhand` / `DefaultStardewAdapter.swapOffhandWith` 同一口径）；切主手 = `setSelectedSlot` + `ServerboundSetCarriedItemPacket`。它不是新功能，是旧框架工具的等价重写。
- **`FarmDecision.hasHoe()`**：旧 `InvUtils.find(...).found()` 改为等价的 `getContainerSize()` 遍历（含副手），命中 `HoeItem` 即真，判定域不变，故不引入对 task 包私有类的跨包依赖。
- **`TillTask` / `FortuneTool` 的 swapBack**：旧框架 `swap(slot, true)` 内部记录原槽、`swapBack()` 还原；新实现显式保存 `previousSelected` 后 `selectHotbar` 切换 / 还原，语义与行为一致。
- 其余类一比一落位，未做拆分（旧类职责单一，不满足拆分依据）。
