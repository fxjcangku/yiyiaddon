## 一、这个项目是什么

`yiyiaddon`：Minecraft 26.1.2（内部 1.21.11，Mojang 官方映射）的 **Fabric 独立客户端模组**，从旧项目 `D:\mcaddon\26.1.2`（Meteor 客户端扩展，自有包 `com.example.addon`，404 个 .java）**整体复刻**而来。

技术栈：Fabric Loader 0.19.5 / Fabric API 0.155.2+26.1.2 / Loom 1.17.20 / Java 25 / Baritone 1.18.0 / Skija 0.143.16。

---

## 二、迁移口径（唯一权威声明，2026-09-14 定稿）

> **旧项目的功能、模块、互相关联，全部复刻过来，一样不少；唯一变化是 UI 外壳。**
> 旧项目的文字与交互 + 本项目现有主题与按钮 = **文字照搬、交互对齐、壳换掉**。
> 新项目**自研框架**，彻底脱离 Meteor 及一切第三方客户端框架。

详细展开与例外清单见 [`01-总纲-迁移口径与复刻原则.md`](01-总纲-迁移口径与复刻原则.md)。**任何与本口径冲突的旧表述，一律以 01 号文件为准。**

三条不可动摇的底线：

1. **功能与关联不变**：模块、模块间关联、数据链路、指令、自检、播报、点位/身份数据结构全部照旧（六份基准即为逐字依据）。
2. **只换 UI**：界面外壳用本项目自研 Skija 体系与主题重写；按钮文字与点击作用逐字照旧，一个字不改。
3. **不引入第三方客户端框架**：代码、注释、界面、对外文案均不得出现旧框架名称或 API。

例外（唯一允许不复刻的清单，来自 `开发习惯.md` 第 43 条）：明文密码外发类、水印、指令名上报 Mixin、示例 HUD、主题模块、全部 recognition/adapter 死代码层、`StardewProfileStore`。
