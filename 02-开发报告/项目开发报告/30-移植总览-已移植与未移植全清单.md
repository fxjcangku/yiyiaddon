### 2.2 三个模块的联动链（已打通，逐条可查）

```
.id 物品（IdIdentifyModule / IdentityCommand）
   → IdentityService.addItem(...)  → 落盘 <游戏目录>/AutoChest/items/*.json
   → IdentityService 通知监听器
自动箱子「目标物品」（AutoChestPage → SelectorScreen）
   → 数据源 IdentityService.allItems()（= 旧 ItemIdManager）
   → 选中键存 IdentityTargetConfig（= 旧 ItemTargetSetting）
取物（ChestInteractionService）
   → IdentityTargetConfig.selectedItems(IdentityService.shared()) 逐格匹配
ID 删除 → pruneInvalid → 播报「有 N 个目标 ID 已失效，已从选择器移除」
```

与旧项目完全一致：**数据源唯一，自动箱子不建第二套物品库**（旧 `AutoChestModule.java:50-51`）。
