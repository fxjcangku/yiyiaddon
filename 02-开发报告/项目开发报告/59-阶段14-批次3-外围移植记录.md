## 6. 修改内容（相对旧项目的全部改动）

1. **包与类落位**：旧模块类拆到 7 个文件；`ProfessionChoice` / `Mode` / `State` 三个内嵌枚举独立成顶层枚举（`VillagerProfessionChoice` / `VillagerTradeMode` / `VillagerTradeState`，取值与顺序未改）。
2. **快速停止键承载**（D4）：旧独立 `KeybindSetting`（默认 none，存模块设置）→ 落本项目模块快捷键体系，键位 id `module.villager.stop`（`ModuleKeybindManager` 录制 + `module-state.json` 持久化），模块每 tick 轮询并按旧 `isPressed()` 语义做**按下跳变**判定；触发文案 `§e检测到快速停止键，停止交易` 逐字保留。因此设置载体里**不再有** `stopKey` 字段（单一真值）。
3. **设置项承载**：旧 7 静态项 → `VillagerTradeSettings` 字段 + 控制台设置页行；13 职业物品选择器 / 13 价格上限 / 13 多任务勾选 / 附魔书 → 同一载体的分组读写方法 + 选择器接线；**购买量 13 项按 D6 不做界面**（旧项目该行 `visible(() -> false)` 恒隐藏，其描述文本仅在代码注释中留档）。
4. **设置页形态**（D3）：旧框架三个分组（`目标物品` / `价格上限` / `多任务职业`）+ `visible()` 联动 → 控制台「按职业折叠分组」+ PIPELINE 时的 `多任务职业` 折叠组；**模式与职业联动判据 1:1**（旧 `:162` / `:202` / `isProfessionVisible :294-301`），行名逐字保留（`<职业>交易` / `<职业> 价格上限`（含空格）/ `图书管理员附魔书` / 13 职业勾选行）。
5. **ESP 按实测行为迁移**：旧 `ContainerESP` 的 javadoc 写「显示文字标签」，实测只画线框（`text` 仅用于判色）。新实现**只画线框**，字牌属旧项目注释与实现不符的误记，按第 76/167 条取证订正并在 55 号 §2.1 / §2.8 / §八 同步修正（见 D-14-14）。
6. **新增中文 javadoc**（第 208 条）：每个新类写职责与关键约定，每个非平凡方法写「做什么 / 为什么 / 关键判据」；旧项目注释原文保留（含静默容器的创造背包 NPE 原因、职业 Record 比较说明等）。
7. **注册**：`AddonModules.createModules()` 追加 `new AutoVillagerTradeModule()` 一行 + import；分类 `automation`（旧 `CATEGORY_AUTOMATION`），同分类权重 `order = 30`（与农场/挖矿/箱子一致）。
