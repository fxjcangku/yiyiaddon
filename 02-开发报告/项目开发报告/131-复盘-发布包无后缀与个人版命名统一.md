# 发布包无后缀与个人版命名统一

日期：2026-09-19

用户要求：混淆发布包不带后缀，个人版保留后缀。

## 改动

- `build.gradle` 将普通 JAR 的分类后缀设置为 `personal`，增加 `buildPersonal` 构建入口。
- `gradle/obfuscation.gradle` 取消发布 JAR 的 `obfuscated` 文件名后缀，保留原有内部任务名和保护流程。增加 `releaseZip`，在保护检查通过后打包，`buildRelease` 自动生成 ZIP。
- 映射备份保留不可覆盖原则。若同一内容摘要的历史记录仅产物名称不同，保留原记录并写入 `产物命名更新.txt`。
- 更新备份目录说明和发布页面使用说明。旧命名的本地构建产物移入 `build/历史命名产物/` 的摘要子目录，未删除历史映射与测试归档。

## 验证

执行 `./gradlew build buildPersonal buildRelease --console=plain`，退出码 0，构建成功。日志：`build/artifact-naming-check.log`。
