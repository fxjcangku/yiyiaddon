## 二、铁律：界面自研与参考边界

### 2.1 主题与按钮样式保持现状，不重新设计

本次界面工作的全部范围只有两件事：把旧项目的**按钮文字**（及页面全部文案）套入本项目现有主题；实现与旧项目**相同的交互方式**。

| 资产 | 状态 | 禁止事项 |
| --- | --- | --- |
| 主题与配色（`ui/theme/ClickGuiThemeColors` 及各主题类） | 固定不变 | 禁止重新设计主题、禁止新增主题、禁止调整配色、禁止引入旧框架的主题体系（`GuiTheme` 系列） |
| 按钮样式与尺寸（`ui/widget/Button`、`IconButton`、`ui/component/ButtonRow`） | 固定不变 | 禁止改动其视觉规格，禁止复制仿制旧框架的 `WButton`；按钮大小由本项目自动适配，不参照旧项目的固定宽度与展开方式 |
| 组件（`ui/component`、`ui/widget`、`ui/page`） | 固定不变 | 只准复用，禁止引入旧框架的任何界面组件（`WindowScreen` / `WTable` / `WMinus` / `WPlus` 等） |

### 2.2 参考旧框架源码的边界

| 维度 | 判定 |
| --- | --- |
| **允许**：交互结构与功能逻辑 | 选择器是「双栏 + 加减」还是「分组 + 勾选」；搜索按哪些字段过滤；点选后是否立即生效；是否需要整表重建；有无「全选」「折叠」 |
| **禁止**：视觉与代码 | 配色、圆角、字号、间距、控件尺寸、图标资源、类结构、方法命名 |

**判定口径**：

- 「旧框架是这样画的，所以我们也这样画」= 违规
- 「旧框架是这样交互的，所以我们也这样交互」= 合规

### 2.3 配置页面公式

**旧项目的文字与交互，套入本项目现有主题。**

| 层 | 来源 | 要求 |
| --- | --- | --- |
| 按钮文字、字段标签、区块标题、页面标题、提示与确认文案 | 旧项目源码 | 逐字复刻，含 `§` 颜色码，改一个字即不合格 |
| 交互方式（按钮点击行为、页面层级、跳转路径、操作对象） | 旧项目源码 | 逐项对齐，功能不得增删 |
| 主题、配色、按钮样式、控件样式 | 本项目现有 | 保持现状，不重新设计、不参照旧项目外观 |

按钮尺寸与排布一律由本项目控件自动适配（`Button` 的尺寸档位、`ButtonRow` 的满宽或等宽平分），**不参照旧项目按钮的大小、固定宽度与展开方式**。

一句话：**文字换、交互对齐，壳不动。**

### 2.4 文本渲染口径

页面文本必须经 `ui/render/MinecraftText` 渲染。旧项目文案带 `§` 颜色码，禁止在绘制前手工剥离颜色码、禁止改写为纯文本、禁止替换为本项目的其它配色方案。

### 3.2 差值原因（如实记录）

| 原因 | 说明 |
| --- | --- |
| 数据层先迁移 | 第 07 阶段先完成了 `IdentityService` / `IdentityActions` / 5 个仓库 / 4 个模型，界面留在骨架状态 |

## 四、旧框架源码参考的合规判定举例

### 4.1 目标/方块选择器

| 项 | 判定 | 说明 |
| --- | --- | --- |
| 采用「双栏：左全部 + 右已选，每行右侧加减号」 | 合规 | 交互结构 |

| 搜索同时匹配中文名与技术 ID | 合规 | 功能逻辑 |
| 方块图标用「方块转物品栈」渲染 | 合规 | 功能实现路径（图标来源是 Minecraft 本身） |

| 用旧框架的配色、圆角、控件尺寸 | 违规 | 照搬视觉 |
| 用旧框架的占位图片资源 | 违规 | 引入外部素材 |

### 4.2 实体/怪物选择器

| 项 | 判定 | 说明 |
| --- | --- | --- |
| 单栏分组（Animals / Water Animals / Monsters / Ambient / Misc）+ 勾选框 | 合规 | 交互结构；勾选框在旧框架中对应实体选择器形态，与本项目的按钮体系不冲突 |

## 六、禁止事项

1. 禁止引入、复制、仿制旧框架的任何界面组件、主题、配色、图标资源。
2. 禁止以「参考旧框架」为理由新增控件或改动既定控件。
3. 禁止重新设计主题、禁止新增主题、禁止调整配色、禁止改动按钮与控件的视觉规格。
4. 禁止改写旧项目原文（含 `§` 颜色码），禁止剥离颜色码后按本项目配色重绘。
5. 禁止在界面里新增旧项目不存在的按钮文字；本项目建设性文案须单独留档说明。
6. 禁止使用滑块控件（第十八章第 123 条）。
7. 禁止把模块页面集中堆在顶层 `ui/`，模块页面必须放模块包内的 `ui`（第十四章第 83 条）。
