## 二、查出的偏差与修复（全部已修复 + 复验）

### 偏差 1（严重）：`highlightText` 颜色写错

- **事实**：旧基类 `YiyiaddonModule.highlightText`（`:168-170`）= `§a§l<文本>§r§f§l`（**亮绿色粗体**，尾部延续粗白）。我在 `AutoFarmModule` 写成了 `§f§l`（白色粗体）。
- **影响面**：启动报告全部高亮（启用作物 / 作物箱 / 物品类型 / 农田范围 / 卸货补货数量 / 收割模式）与 `statusSummary` 的作物名——启动报告是模块最大的用户可见资产。
- **修复**：改为 `"§a§l" + text + "§r§f§l"`，并补 `highlightFunction`（`§b§l` 亮青粗体，旧 `:173-175`）。
- **复验**：编译通过；文案机对命中。

### 偏差 2（严重）：`statusSummary` 模式名颜色写错

- **事实**：旧 `AutoFarmMatrix.statusSummary`（`:748-750`）用 `highlightFunction("批量"/"单个")`（**亮青色粗体**），我写成了白色粗体。
- **修复**：改调 `highlightFunction(...)`。
- **复验**：同上。

### 偏差 3（中）：`.farm` 兜底文案缺失

- **事实**：旧 `NongChangCommand.module()`（`:294-298`）在模块未注册时播报 `§6自动农场模块未注册。`；我的 `FarmCommand.module()` 静默返回 null。
- **修复**：补回兜底播报（正常引导下不触发，但旧项目有就必须在）。
- **复验**：编译通过；文案机对 120/120。

### 偏差 4（**最严重**）：水源模块 10 个设置项无承载界面、11 条文案缺失

- **事实**：批次 3 只写了 `WaterESPModule` + `WaterSettings`（数据载体），**没有写任何页面**——`Module.page()` 返回默认 null 会落模块中心占位页，10 个设置项（扫描半径 / 渲染距离 / 显示灌溉范围 / 范围颜色 / 显示建议点 / 建议点颜色 / 建议点样式 / 显示水源方块 / 水源方块颜色 / 水源方块样式）在游戏里**无处显示、无法修改**；分组名 `灌溉范围显示 / 建议放水点 / 高级选项` 等 11 条文案机对全部缺失。而 54 号报告错误地写了「经控制台通用机制进入设置侧导航的模块页」——报告与实际不符。

- **修复**（照阶段 12 管理员检测先例：薄壳模块页 + 控制台承载）：
  1. 新增 `feature/water/ui/WaterPage.java`——薄壳模块页（状态条 + `§b打开控制台`，无自造说明文案，旧项目本无使用说明）；

  3. `WaterESPModule.page()` 接线。
- **复验**：编译 EXIT=0；水源文案机对 **23/23 全命中**。
