## 3. 与旧项目的差异清单（逐条）

1. **包名 / import**：全部迁到 `com.yiyiaddon.feature.stardew.*`（旧包名与目录结构不复用）。
2. **注释里删掉旧框架名**：2 处（规则 161）。
3. **播报前缀**：`§f§l[星露谷农场]§r§l`，**不含** yiyiaddon 段（既有决定）。
4. **排版器**：本项目排版器已补全为旧项目完整版（真实字体测量 ＋ 一像素空白对齐），详见 `04-本批触碰的非 stardew 文件`。
5. **设置落盘**：旧为 NBT 中文键；新为模块设置 JSON（键名 camelCase，与本项目其它模块一致）。业务 JSON（选择 / 后勤 / 作物数量计划 / 农田记忆 / 收获规则 / 点位 / 季节绑定）**中文键与磁盘路径一字未改**。
6. **六类选择**：内存镜像在 `StardewSettings`，按 ServerKey 落盘仍走 `StardewSelectionStore`（`StardewFarm/selection/<服务器>.json`）。
7. **界面**：4 张旧设置卡与控制台 6 页全部按新壳重写；文案、tooltip、页签名、页脚灰字、二次确认正文逐字保留。
8. **季节识别**：旧直接读数据包文本；新项目用核心新增的「服务器文本」事件（只读文本，模块拿不到包对象）。
9. **3 个行为差异的补齐**（原为旧项目能力、新框架缺失）：
   - 后台开箱屏蔽 → `ClientEvent` 加取消令牌，`SCREEN_OPEN` 可取消；模块判定成立时 `event.cancel()`。
   - 开关播报重复 → `ModuleManager.setEnabledSilently(...)` ＋ `Module.suppressEnableAnnounce()`（默认 false）。
   - 主菜单误触自检 → 自检抽为 `runStartupCheck()`，只在世界内执行，进服补跑一次。
10. **收割取手的兜底（用户点名改的行为，非移植）**：旧实现是「主手空 → 主手；否则切空热键栏槽；9 格全满 → 副手；副手也占着 → 放弃」，
    于是「热键栏 9 格全满 + 副手有东西」时永远收不了菜，且一声不响（实机 20:16 复现，日志 `[星露谷] 收割取手：没有空手`）。
    现改为：这一步先把副手物品**暂放到背包空格**（原版「F 键换副手」的同一个 `SWAP` 点击，从后往前挑空格），
    腾出一只空手用副手收割，任务结束（`replan`）或停机时换回；那一格换回前会被占住不再借用。
    背包也没有空格时才真正放弃（此时聊天播报一次 + 日志一行）。改动位置：`StardewFarmExecutor.prepareHarvestHand / parkOffhand / restoreParkedOffhand`、
    `DefaultStardewAdapter.swapOffhandWith`、`StardewAdapter.swapOffhandWith`（新增接口方法）。
11. **副手认作一只手（用户点名改的行为，非移植）**：旧实现只认快捷栏 + 背包（`StardewInventoryService.findSlotEntry/findSlotSeed` 只扫 0~35），
    于是「水壶放副手 → 自检报『背包缺少已选水壶』、浇水 / 补水 / 洒水器维护全失效」，还会出现「明明没补水，脚本却判定补满收工」
    （读不到壶 → 水量 UNKNOWN → 按允许继续的口径走完）。现改为：
    - **计数与查找**：`count / countSeed / countProduce / findSeedStack / countByDisplay` 与 `findSlotEntry / findSlotSeed` 全部把副手算在内，命中副手返回新增的 `StardewInventoryService.OFFHAND_SLOT`（40）。
    - **动作**：`StardewFarmExecutor` 新增 `activeHand`，工具 / 种子在副手时 `holdEntry / holdSeed` 走 `holdOffhand()`（不挪物品，交互包带副手）；
      浇水、播种、施肥、补水、灌洒水器的发包与水量 / 容量读数全部改用 `activeHand`。关掉「自动切换水壶」也认副手（`resolveHandFor`，同样不挪物品）。
    - **读数取值**：新增 `StardewInventoryService.stackAt(slot)`，副手一律走 `getOffhandItem()`，不依赖 `Inventory` 下标约定。
    - **壶不见了就停机**（用户选择「停机报错」）：`StardewFarmExecutor.blockedByMissingCan()` 在浇水 / 补水 / 维护前先判「已选壶在不在快捷栏 / 背包 / 副手」，
      不在 → `StardewCoordinator.stopForMissingCan()` → 模块停机并播报「找不到水壶」；`verifyRefill` 里「读不到水量」也不再直接判定补满。
    - 自检用的 `StardewPointActions.preferredAvailableCan()` 走同一个 `findSlotEntry`，因此副手放壶能过自检，不再要求必须放背包。
