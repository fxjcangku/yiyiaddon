### 3.1 工具链版本（取自 gradle.properties）

| 组件 | 版本 |
| --- | --- |
| Minecraft | 26.1.2 |
| Fabric Loader | 0.19.5 |
| Fabric API | 0.155.2+26.1.2 |
| Fabric Loom | 1.17.20 |
| Gradle | 9.6.0 |
| JDK 工具链 | 25 |
| 字节码 release | 21 |
| Baritone | baritone-fabric 1.18.0（LGPL-3.0） |
| Skija | skija-shared 0.143.16 + types 0.2.0（Apache-2.0） |

版本来源说明：这些版本不是凭记忆填写，而是取自本机已在 Minecraft 26.1.2 上验证可 build / runClient 的既有工程配置。

字节码 release 取 21 的原因：Mixin 注解处理器最高只支持 class file 65（Java 21），工具链本身仍为 Java 25。

### 3.2 26.1.2 的关键环境差异与应对

1. **GUI 模型不同**：26.1.2 已不存在 `GuiGraphics`，取而代之的是 `GuiGraphicsExtractor` 抽取阶段模型。因此 PVPUtils 基于 `render(GuiGraphics, int, int, float)` 的屏幕实现无法直接使用，必须重写渲染入口。
2. **帧末直绘**：新增 `RenderTargetMixin`，在 `RenderTarget#blitToScreen` 的 HEAD 处注入，且只在当前 RenderTarget 等于主 RenderTarget 时，调用 `SkiaScreen#renderSkiaFrame()`。此时机能拿到包含世界与 HUD 的完整主 Framebuffer。
3. **主 Framebuffer 名字获取**：26.1.2 中 `RenderSystem.getDevice()` 不再直接是 `GlDevice`，GL 后端被包在 GpuDevice 内部。通过新增 `GpuDeviceAccessor`（`@Accessor("backend")`）配合 AccessWidener（`accessible class com/mojang/blaze3d/opengl/GlDevice`）解包取得，取不到时回落到 `glGetIntegerv(GL_DRAW_FRAMEBUFFER_BINDING)`。
4. **输入 API 变更**：26.1.2 使用 `KeyEvent`、`CharacterEvent`、`MouseButtonEvent`、`PreeditEvent` 等记录类型事件，输入分发按新 API 实现。
5. **原生输入法集成**：使用 `Minecraft#onTextInputFocusChange` 与 `Screen#preeditUpdated`，不引入 JNA / Imm32。
6. **Loom 1.17 行为变化**：不再需要手工声明 refmap，`loom.mixin` 配置块已移除。

## 五、PVPUtils 风格 UI 当前移植情况

### 5.1 移植原则

严格遵循「先移植，再改 UI」：本轮**没有**重新设计、重新配色、重新布局、换结构，窗口几何、侧栏尺寸、动画曲线、控件样式均保持 PVPUtils 原样。

### 5.2 已迁移的系统

**渲染层（com.yiyiaddon.ui.render）**

- `SkiaGlState`：GL 状态保存与还原（纹理单元、FBO、blend、pixelstore 等）
- `SkiaGlBackend`：Skija DirectContext 与主 Framebuffer 绑定
- `SkiaBlurRenderer`：面板模糊（sRGB/linear 滤镜链高斯模糊）
- `FontRenderer`：字形渲染（含图标字体）
- `SkiaScreen`：屏幕基类（已按 26.1.2 重写渲染入口）
- `ImeBridge`：输入法桥接（新建，非 PVPUtils 派生）

**主题体系（com.yiyiaddon.ui.theme）**

- 基础：ClickGuiTheme、ClickGuiThemePalette、ClickGuiThemeMetrics、ClickGuiThemeColors、ClickGuiThemeManager
- 实现：WhiteTheme、DarkTheme、GrayTheme、LightBlueTheme、DefaultClickGuiTheme、vape/VapeTheme

**控件（com.yiyiaddon.ui.widget，共 10 个）**

SettingWidget、SettingModule、SettingToggle、SettingSlider、SettingCycle、SettingTextBox、SettingPasswordBox、SettingButton、SettingColorPreview、SettingLink

**页面与屏幕**

- `BasePage`、`SearchResultsPage`（PVPUtils 派生）
- `ClickGuiScreen`（由 NewSettingsScreen 移植重写，740x500 卡片、190 侧栏、3 个 Tab）
- `TestPage`、`InterfacePage`、`SettingsPage`（新写，见 5.3）

**快捷键**

- `ModuleKeybindManager`：绑定录制、持久化、触发；默认绑定为右 Shift；支持鼠标按键编码

### 5.3 业务内容替换为测试数据

PVPUtils 的全部业务页面（Combat / Render / Tools / Optimize / Misc / Theme / AddServer / Terms）均未移植，替换为三个只有 UI 验证数据、不执行任何游戏业务的页面：

- **测试页**：开关、滑条、枚举选择、文本输入、按钮、颜色、一级展开、二级设置、条件显示、12 条长列表滚动
- **界面页**：面板主题（跳转主题预览网格）、界面大小（75/100/125）、面板模糊开关、模糊强度、模糊底色、滚动速度
- **设置页**：GUI 快捷键录制、Baritone 汉化开关、重置测试状态

### 5.4 输入处理

输入分发顺序为：快捷键录制 → 文本输入框 → ESC → 搜索框。`charTyped` 转发至文本输入框，`preeditUpdated` 转发至输入法预编辑绘制。屏幕关闭时统一清理文本焦点、重置输入法状态、销毁 GL 后端并保存配置。

### 5.5 最小配置系统

`com.yiyiaddon.config.AddonConfig`，写入 `config/yiyiaddon.json`，全部字段用显式 JSON 读写（不用反射序列化），字段缺失或文件损坏时静默回落默认值，不阻断启动。

当前仅保存 UI 自用状态：主题、界面缩放、面板模糊、模糊强度、模糊底色、滚动速度、GUI 快捷键、Baritone 汉化开关，以及十个 UI 测试值。**不包含任何未来业务模块的配置框架。**

配置持久化已实际验证：运行后配置文件被游戏回写，内容与读取一致（测试用的绑定值被原样保留），说明关闭重启后 UI 基础配置可正常保留。

### 5.6 主题注册现状

`ClickGuiThemeManager` 中只注册 White / Dark / Gray 三个主题；LightBlueTheme、DefaultClickGuiTheme、VapeTheme 在上游同样未注册。本轮**刻意保持原样**，未做任何视觉层面的增删改。

4. **Skija 帧缓存路径未移植**。PVPUtils 的 `SkiaRenderer` 栅格缓存依赖 1.21.11 的 `GuiGraphics#blit`，26.1.2 不存在该 API，因此 ClickGUI 每帧直接向主 Framebuffer 直绘。功能正常，但长时间高负载下的渲染开销尚未评估。
5. **主题注册数量少于主题类数量**。`ClickGuiThemeManager` 只注册 White / Dark / Gray，而主题类共有 5 个（LightBlue、Default、Vape 与上游一致未注册）。这是刻意保持原状，后续若启用需要单独决定。
6. **Git 全局身份是占位符**。本机 `user.name` 为「你的 GitHub 用户名」、`user.email` 为「你的 GitHub 提交邮箱」。本次基线提交是用临时环境变量修正作者后提交的，全局配置未改动。若不修正，后续新提交的作者仍会是占位符。
7. **推送依赖手动代理参数**。直连 GitHub 会因 schannel 握手失败而无法推送，需要带 `-c http.proxy=http://127.0.0.1:7890 -c https.proxy=http://127.0.0.1:7890`。是否把代理写入 git 配置需要用户决定。
8. **缺少 .gitattributes**。Git 已提示 CRLF 转换警告（LF 将被替换为 CRLF），不影响构建，但跨平台协作时建议统一换行策略。
9. **环境强依赖 JDK 25 工具链**。字节码 release 为 21，但工具链要求 Java 25，构建机需要相应 JDK。
10. **无自动化测试**。项目当前没有单元测试或集成测试任务（`test` 为 NO-SOURCE）。
