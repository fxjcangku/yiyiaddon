## 1. 本次迁移目标

把自动图书管理员除「模块入口与界面」以外的全部可编译逻辑搬进本项目，满足四条硬约束：

1. **判据逐条照搬**：27 态状态机、转换表、26 个状态处理器、工位两遍探测、讲台放置朝向同步、静默交易协议、库存计数成交验证、全部阈值（60 / 200 / 15 / 10 / 3 / 2 / 200 / 1200 / 100 tick）一条不改；
2. **零旧框架依赖**：设置 / 事件 / GUI / 物品栏原语全部换本项目实现，代码中不得出现旧框架包名；
3. **死件不搬**（D1）：第 43 条覆盖的 `adapter/` + `recognition/` 3 文件不搬；另 6 处零调用死件（`LecternService` / `NoOpMovementService` / `calculateMarkerBlockPosition` / `EnchantmentService` 三个默认方法 / `setServices`+`getServices` / `softReset`+`restart`）不搬并登记；
4. **同源收敛**（第 169 条）：交易发包原语落公共层 `platform/container/MerchantTradeAccess`；职业判定收敛为 `Holder#is(Identifier)` 一处口径。

4. **交易协议抽公共**（D-15-03）：报价选中（`ServerboundSelectTradePacket`）、结果槽快速移动（`ContainerInput.QUICK_MOVE` 槽 2）、关界面三步改调 `platform/container/MerchantTradeAccess`。

6. **职业判定收敛**（D-15-04）：`Holder#is(ResourceKey#identifier())` 一处口径，与自动村民交易模块同源。
7. **阈值具名化**（第 208 条）：把旧项目散落在方法体里的 60 / 200 / 15 / 10 / 3 / 2 / 200 / 64 / 18 / 36 等魔法数提为具名常量（取值与语义未变），例如 `FIND_STATION_TIMEOUT_TICKS = 60`、`PLACE_SETTLE_TICKS = 15`、`TRADE_DATA_READY_DELAY_TICKS = 10`、`UUID_FALLBACK_RADIUS = 64`、`INVENTORY_SLOT_COUNT = 36`。
