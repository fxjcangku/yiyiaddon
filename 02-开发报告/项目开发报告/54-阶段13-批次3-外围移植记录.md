## 4. 分类调整说明

- **设置与壳分离**：旧项目把设置项直接建在模块构造器（Meteor Setting 体系）；本项目设置数据载体归 `config/`，模块只持有载体并在 `loadSettings/saveSettings` 编解码（第 91、173 条），界面控件一律在 `ui/console/` 现场读写载体 + `persistSettings()` 立即落盘。
- **锚点不再落隐藏设置项**（D-13-02）：六锚点原始串存 `module-state.json` 模块设置块内，**键名沿用旧项目隐藏设置键**（`_anchor_start` 等），旧存档无需迁移。
- **逐作物项**：载体键 = 作物枚举名（`WHEAT` 等），界面行名 = 旧生成式中文名（`小麦-卸货数量`），两端职责分开。
- **渲染层归属**：旧 `FarmRenderer` / `WaterESPModule` 的 `Render3DEvent/Render2DEvent` 事件在新框架不存在对应物，统一走第 147 条既定路线（`WorldOverlay` + `EspRenderer`），模块只描述「画什么」。

## 5. 旧框架依赖清理情况

- 本批次无旧项目源码 import 进入新代码；`feature/autofarm/` 与 `feature/water/` 下 `meteordevelopment` 命中 **0**。
- 框架层等价改写点：
  1. `Render3DEvent / Render2DEvent` → `WorldOverlay.Layer`（`renderer.box / blockBox / text`，第 160 条先填充色后描边色口径照 `EspRenderer` 签名）；
  2. `ShapeMode`（Meteor）→ 本项目 `ui/render/world/ShapeMode`（同名同值，标签 `线框/面/两者` 第 143 条）;
  3. `SettingColor` → `EspColor`（调色板唯一入口，第 146 / 151 条）;
  4. `Modules.get().get(X.class).toggle()` → `ModuleManager.setEnabled(id, !isEnabled)`（模块页水源开关）;
  5. `OpenScreenEvent`（携带屏对象可取消）→ `SCREEN_OPEN` 事件（载荷为界面类名，`Class.forName` 等价判定，与自动挖矿同一做法）；
  6. `BlockListSetting`（候选全注册表 + filter）→ `SelectorScreen`（候选集直接给定，D-13-04）。
