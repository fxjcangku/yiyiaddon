# yiyiaddon UI 风格方案（四套）

**日期：2026-09-14**
**状态：方案待选，未实施**
**前置：已完成的材质与两栏重构见 `2026-09-14-iOS透明玻璃风格开源参考与改造方案.md`**

---

## 零、先说一个关键结论

搜索到的 `auraglass` 在 4.1.0 版本做了一次全库返工，原因写得很直白：中性玻璃表面原本是**深灰渐变**，结果面板看起来是一块深色板子，而不是玻璃。改法是把中性表面换成
**低透明度白色渐变霜（low-alpha white gradient）叠在一层极淡的烟灰色薄纱上**，这样面板才会吸收背后画面的颜色，像真磨砂玻璃。

这正是当前 yiyiaddon 界面的问题。现在卡片与底板的填充是**实色**（`#1C1C1E`、`#232327` 这类），所以无论圆角与阴影怎么调，观感都是「深色方块」。

下面四套方案的共同前提就是把填充从实色换成**白色低透明度渐变霜**。

---

## 一、技术可行性（先划边界）

| 能力 | Skija 支持 | 说明 |
| --- | --- | --- |
| 线性渐变 | 支持 | `Shader.makeLinearGradient(x0,y0,x1,y1,colors,positions,GradientStyle)` |
| 径向渐变 | 支持 | `Shader.makeRadialGradient(cx,cy,r,colors,positions,GradientStyle)` |
| 扫描渐变 | 支持 | `Shader.makeSweepGradient(...)` |
| 着色器绑定 | 支持 | `Paint.setShader(...)` |
| 叠加发光 | 支持 | `Paint.setBlendMode(BlendMode.PLUS / SCREEN)` |
| 降采样模糊 | 已有 | 项目内 `SkiaBlurRenderer` |
| 顶部内高光 | 可做 | 1px 高光描边 + 顶部渐变遮罩 |
| 真实折射 / 色散 | **做不了** | 需要对背景做位移采样与色差，Skija 直绘管线无此能力 |

结论：四套方案都只依赖「渐变 + 模糊 + 高光 + 阴影」，全部可落地；折射一律不做。

---

## 二、方案 A：极夜霜玻璃（Midnight Frost）

**定位**：最克制，最接近 iOS 26 暗色原生观感。整套界面只有一种彩色。

| 令牌 | 取值 |
| --- | --- |
| 底板 | `#0A0A0C` |
| 玻璃填充 | 线性渐变 180 度：`rgba(255,255,255,0.09)` → `rgba(255,255,255,0.03)`，叠 `rgba(12,12,16,0.55)` |
| 顶部内高光 | `rgba(255,255,255,0.18)`，1px |
| 玻璃边框 | `rgba(255,255,255,0.10)` |
| 悬停填充 | `rgba(255,255,255,0.06)` |
| 强调色 | `#0A84FF`（唯一彩色） |
| 文字 | `#FFFFFF` / `rgba(235,235,245,0.60)` / `rgba(235,235,245,0.30)` |
| 圆角 | 容器 22 / 卡片 16 / 控件 10 |
| 阴影 | 外 `0 8px 32px rgba(0,0,0,0.45)`，内 `inset 0 1px 0 rgba(255,255,255,0.10)` |
| 渐变使用范围 | 仅选中项、进度条、开关轨道 |
| 动效 | 0.28s 临界阻尼，按压缩放 0.97 |

**参考**：iOS 26 Liquid Glass 参考（玻璃只用于导航层、tint 只表达语义）、auraglass 4.1 白色霜化结论。

**适合**：想在暗色游戏画面里保持干净、不抢画面，长期看不腻。
**风险**：辨识度最低，可能仍被评价为「太素」。

---

## 三、方案 B：极光紫青（Aurora）

**定位**：辨识度最高，高级感最强。深色玻璃 + 缓慢漂移的极光光斑 + 紫青渐变强调。

| 令牌 | 取值 |
| --- | --- |
| 底板 | `#050510` |
| 背景光斑一 | 径向渐变，中心 `rgba(124,106,239,0.35)`，半径约屏宽 0.7，位置左上 |
| 背景光斑二 | 径向渐变，中心 `rgba(78,205,196,0.22)`，半径约屏宽 0.6，位置右下 |
| 光斑动效 | 60 秒一个周期缓慢位移，幅度不超过屏宽 8%，禁止高频闪烁 |
| 玻璃填充 | `rgba(10,10,28,0.72)` |
| 玻璃边框 | `rgba(255,255,255,0.06)` |
| 悬停填充 | `rgba(255,255,255,0.10)` |
| 强调渐变 | 135 度 `#7C6AEF` → `#4ECDC4` |
| 强调光晕 | `0 0 24px rgba(124,106,239,0.35)` |
| 文字 | `rgba(255,255,255,0.93)` / `0.50` / `0.28` |
| 圆角 | 卡片 16 / 控件 10 / 小元素 6 |
| 动效 | 0.25s `cubic-bezier(0.4, 0, 0.2, 1)` |

**参考**：JARVIS 深色玻璃令牌集（上表数值即取自它）、`farvist` 的 mesh-aurora 背景类、Arc 浏览器的极光紫渐变（`135deg #f093fb → #f5576c`）。
**额外借鉴**：`@kodlyft/liquid-ui` 的玻璃配方四件套——背景模糊 + 饱和度提升、顶部内高光、柔和内阴影、镜面光泽叠加。

**适合**：想要「一眼记住」的视觉签名。
**风险**：光斑会与游戏画面争夺注意力；长时间游戏可能觉得吵。

---

## 四、方案 C：霜白亮色（Luminous Light）

**定位**：iOS 亮色模式。白色磨砂玻璃叠在游戏画面上，白天与明亮地形下可读性最好。

| 令牌 | 取值 |
| --- | --- |
| 玻璃填充 | 线性渐变 180 度 `rgba(255,255,255,0.82)` → `rgba(255,255,255,0.66)` |
| 玻璃边框 | `rgba(255,255,255,0.70)` |
| 顶部内高光 | `rgba(255,255,255,0.90)`，1px |
| 悬停填充 | `rgba(0,0,0,0.04)` |
| 卡片 | `rgba(255,255,255,0.72)` |
| 强调色 | `#007AFF` |
| 文字 | `#1C1C1E` / `rgba(60,60,67,0.60)` / `rgba(60,60,67,0.30)` |
| 分隔线 | `rgba(60,60,67,0.29)` |
| 圆角 | 容器 22 / 卡片 16 / 控件 10 |
| 阴影 | `0 2px 8px rgba(0,0,0,0.08)`，`0 12px 40px rgba(0,0,0,0.12)` |

**参考**：apple-hig-designer 的 iOS 亮色令牌、darwin-ui 的明度分层思路。
**适合**：明亮场景、白天使用。
**风险**：Minecraft 大量场景偏暗（洞穴、夜晚、下界），白玻璃在暗背景下对比过强，会显得刺眼；且暗背景下玻璃的「霜」看不出来，退化成一块白板。

---

## 五、方案 D：深空靛紫（Deep Indigo）

**定位**：A 与 B 之间。玻璃保持中性，只在关键元素上用渐变强调色点睛。

| 令牌 | 取值 |
| --- | --- |
| 底板 | `#0B0B14` |
| 玻璃填充 | 线性渐变 180 度 `rgba(255,255,255,0.07)` → `rgba(255,255,255,0.02)`，叠 `rgba(11,11,20,0.62)` |
| 玻璃边框 | `rgba(255,255,255,0.08)` |
| 强调渐变 | 135 度 `#5E5CE6` → `#BF5AF2` |
| 强调色（实色用） | `#5E5CE6` |
| 卡片点缀 | 卡片填充叠 `rgba(94,92,230,0.04)` 的极淡渐变，仅左侧偏亮 |
| 强调光晕 | `0 0 18px rgba(94,92,230,0.30)`，只用在选中项与图标底座 |
| 文字 | `#FFFFFF` / `rgba(235,235,245,0.58)` / `rgba(235,235,245,0.28)` |
| 圆角 | 容器 22 / 卡片 16 / 控件 10 |
| 动效 | 0.28s 临界阻尼 |

**参考**：iOS 系统色 indigo `#5E5CE6` 与 purple `#BF5AF2`、GlassKit 的「填充色与文字色必须分开定义」规则。
**适合**：想要一点色彩但不吵，是四套里最折中的。
**风险**：折中意味着辨识度与克制都只拿到一半。

## 六、四套方案对比

| 维度 | A 极夜霜玻璃 | B 极光紫青 | C 霜白亮色 | D 深空靛紫 |
| --- | --- | --- | --- | --- |
| 彩色数量 | 1 | 2 渐变 + 2 光斑 | 1 | 2 渐变 |
| 暗场景表现 | 好 | 好 | 差 | 好 |
| 辨识度 | 低 | 高 | 中 | 中 |
| 长时间耐看 | 最好 | 一般 | 一般 | 好 |
| 与游戏画面争抢 | 最小 | 最大 | 大 | 小 |
| 实现复杂度 | 低 | 中（光斑动画） | 低 | 中（卡片渐变） |

## 七、共同实现落点

无论选哪套，改动集中在四层，业务代码不动：

| 层 | 改动 |
| --- | --- |
| `ui/theme` | 令牌新增：玻璃渐变起止色、强调渐变起止色、光晕色、内高光色、内阴影色 |
| `ui/component/GlassPanel` | 新增 `gradientFill(...)`（线性/径向渐变填充）、`glow(...)`（PLUS 混合外发光）、`innerHighlight(...)`（顶部渐变高光） |
| `ui/component/*Card`、`ui/widget/SettingModule` | 填充由 `GlassPanel.fill` 换成 `GlassPanel.gradientFill`，卡片与设置行同步 |
| `ui/screen/ClickGuiScreen` | 窗口底板与左栏改用渐变霜填充；选中项改用强调渐变 |

渐变着色器按尺寸缓存，避免每帧新建 `Shader` 对象。
