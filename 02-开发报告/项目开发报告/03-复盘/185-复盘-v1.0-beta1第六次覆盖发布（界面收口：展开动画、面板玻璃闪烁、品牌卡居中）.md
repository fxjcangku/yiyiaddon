## 二、修掉的三处界面缺陷

### 1. 模块中心连开多个分组时上下抖动、右侧滚动条被反复挤压

两处根因都指向同一件事：**拿动画中间态当基准**。

- `seedRowShift()` 用「上一帧的动画中间位置 − 这一帧的位置」算行位移动画量。展开一次分组会重建清单（重建本身也是多余的），连着点第二个分组时前一个分组的动画还在跑，位移量被算成巨大负值 → 整块行先跳回去再滑下来。
- `contentHeight()` 返回 `slotTotal`（展开度 × 内容高，逐帧变化）→ 滚动上限与滑块长度每帧重算，滑块被逐帧挤压、滚到底时还被边界钳着弹。

改法：`layoutSlots()` 同趟按展开度**目标值**再排一份收尾态几何（`slotSettled[]` / `settledTotal`），滚动上限与滑块长度改读收尾态（动画全程恒定）；行位移动画起算点改用收尾态顶边（`lastTops` 逐帧留档）；展开 / 收起不再重建清单。

### 2. 开启「面板模糊」后主面板背景持续闪烁

面板玻璃的背景不是现场采样，而是每帧在 GUI 通道之前截下的一张世界帧（`SkiaBlurRenderer.captureWorldFrame()`）。工作区里有一段未提交的优化给它加了「区域没动就最多复用 3 帧」——于是**每 4 帧才真正重采一次**，玻璃在「这一帧刚采过」与「这一帧用旧帧」两种状态下画面有肉眼可见差异，按复用周期闪；面板静止时永远落在复用周期里，所以「一直在闪」。关掉模糊则不跑这条路径，也就不闪 —— 与用户观察一致。

改法：撤掉复用，恢复每帧重采（= 第五次覆盖那版的行为），并删掉随之成为死代码的 `WORLD_FRAME_REUSE` / `worldFrameAge` / `sameBox()`；注释写明为什么不能复用。当初加复用是为省每帧面板大小的纹理分配 + blit（怕帧时抖），帧时那件事已由上面的收尾态几何解决，撤掉没有代价。

### 3. 侧栏品牌卡三行没有居中

标题 / 版本 / 标语原来统一左对齐（`brandX + BRAND_TEXT_PAD_X`），右缘参差。改为**每行各按卡片中线居中**，宽度用 `FontRenderer.measureTextWidth`（与绘制同一套兜底分段规则，中文量得准）；只动 x 不动 y，基线仍与右栏页头同线。`BRAND_TEXT_PAD_X` 随之删除。
