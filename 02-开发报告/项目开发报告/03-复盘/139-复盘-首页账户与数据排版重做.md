# 复盘：首页账户与数据排版重做

日期：2026-09-20

## 一、用户反馈

用户根据真实客户端截图指出：首页不够人性化，排版松散、数据列缺少明确边界、部分内容没有对齐；
账户 UUID 过长且没有首页价值，同时「正版 / 离线」状态离头像和用户名过远。

## 二、取证

- `ui/page/HomePage.java#drawAccountStrip()` 是头像、用户名、UUID 与账户状态的唯一绘制位置；
- 原布局把用户名与 UUID 放在左侧，把账户状态强制右对齐到整张卡片末端，因此同一组身份信息被人为拆散；
- `drawCellRow()` 只在大卡片上绘制文字，没有单元底板，三列账户数据与四列会话数据只能依赖空白判断边界；
- 首页点击区域从第三段「常用模块 / 需要处理」开始，本次上方账户与会话排版调整不改变任何点击命中逻辑。

## 三、设计与修改

1. 账户行改为「头像 + 用户名：正版 / 离线」：
   - UUID 完全从首页隐藏；
   - 身份状态紧跟用户名，不再横跨整张卡片；
   - 正版使用既有成功绿色，离线使用既有提醒橙色；
   - 用户名过长时仍按可用宽度截断，身份状态始终保留。
2. 账户统计与会话统计统一改为等宽数据格：
   - 每项使用主题已有弱底、圆角和边框；
   - 标签、数值、左右内边距和列间距统一；
   - 三列与四列都由同一套宽度公式计算，不再靠散落坐标对齐。
3. 会话区增加「本次会话」标题，明确服务器、维度、坐标、帧率等数据的归属。
4. 卡片总高继续由绘制所用常量反推，滚动总高与下方卡片位置自动同步；未修改模块开关、路由或业务数据来源。

项目仍为独立 Fabric 客户端模组；旧项目未修改。本轮只重排首页现有信息，不新增业务功能。

- `\.\gradlew.bat build --console=plain -q`：EXIT=0；

- 26.1.2 客户端启动验证：已执行，开发客户端正常启动并进入服务器；
- 实际游戏界面观感：待用户在真实 GUI 缩放与窗口尺寸下确认最终效果。

1. 目标：实机核对首页；涉及目录：无代码改动；影响范围：首页；预计修改内容：无。

### 五、验收标准

- 首页不显示 UUID；
- 头像旁显示「用户名：正版 / 离线」，状态带色且间距紧凑；
- 账户与会话数据格边界清楚、同行对齐、没有文字出框；
- 当前状态：代码完成、编译通过、待真实环境验证。

### 六、禁止事项

不改主题配色值、账号判定、后端统计、模块业务、按钮和导航行为；不在没有实机证据时继续扩大重做范围。
