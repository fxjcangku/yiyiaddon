# 复盘：特殊变种（金色 / 巨型 / 变种）的收割口径改为按服务器学习

- 日期：2026-09-22
- 触发：用户实机反馈 —— jmy.seasonmc.xyz 的**巨型菠萝**要用**金锄头左键破坏**（后续补充：空手也能砸、
  拿锄头更快），而老服的金色番茄是**手持金锄头右键**（收完回退植株）。他的原话：
  「能学习吗？不会改了左键，我回去上个服会拿金锄头破坏左键金番茄吧？能不能不同的服务器各自学习记录」
- 结论：特殊阶段的动作**确实随服务器不同**，而执行层原先把「所有特殊阶段共用金锄头右键」写死在代码里
  （见旧注释：「金锄头就是普通原版物品，其他特殊都是右键一起做了」）。因此本服根本收不了，
  而任何「全局改成左键」的修法都会在右键服上把巨型作物砸掉（不可逆）。

## 一、设计取舍：只观测玩家，不自动试探

| 方案 | 结论 |
| --- | --- |
| 全局改成左键破坏 | **否决**：右键服上的巨型作物会被砸掉（用户明确担心的正是这个） |
| 自动试探（先右键、失败就砸） | **否决**：右键服上若因走位 / 距离导致右键连续失败，就会去砸巨型作物，同样不可逆 |
| **观测玩家动作**（采用） | 玩家怎么收的，模块就怎么收：零风险，且「收一棵就学会」，不用玩家做额外配置 |

## 二、改动

### ① 动作枚举与持久化（新）

- `StardewSpecialHarvestAction`：`RIGHT_CLICK`（手持金锄头右键，老服口径，也是**未学到时的默认值**）
  与 `BREAK`（左键破坏，工具不限、拿锄头更快）。与 `StardewHarvestAction` 分开：普通成熟作物的动作
  全服统一（空手右键），不允许也不需要按服务器分叉。
- `StardewSpecialHarvestStore`：落 `StardewFarm/special-harvest/<服务器>/<资源指纹>.json`，
  键为**作物键**，字段为动作 + 动作说明 + 证据（玩家实测）+ 学习时间；读取时复核文件里的服务器与指纹，
  被误复制也不会跨服复用（与 `StardewHarvestRuleStore` 同一套隔离口径）。

### ② 学习：只认「玩家手动 + 金锄头 + 特殊阶段作物 + 那一格确实被收掉」

- 新增 Mixin `MultiPlayerGameModeSpecialHarvestMixin`：
  `startDestroyBlock`（左键）→ 记 `BREAK`；`useItemOn`（右键）→ 记 `RIGHT_CLICK`。
  两个注入点的签名已用 `javap` 对 26.1.2 的 `MultiPlayerGameMode` 逐字核对：
  `boolean startDestroyBlock(BlockPos, Direction)`、`InteractionResult useItemOn(LocalPlayer, InteractionHand, BlockHitResult)`。
- 只做转发，判定全在协调器（`StardewCoordinator#observePlayerSpecialHarvest`）：
  · 主手或副手必须拿着**原版金锄头**（与提示文案一致：让玩家「拿金锄头砸一棵」）；
  · 那一格必须是**特殊阶段作物**（`CropRecognizer.recognizeAtPot` + `CropState.SPECIAL`，
    与扫描 / 验证同源，作物键也取自同一处 —— 学习侧与执行侧不会各算一套身份）；
  · 与本服已知口径相同则忽略（右键服上玩家右键收一棵是最常见的动作，不必反复记）。
- **落盘时机**：先记一条待确认观测，之后 2.5 秒内那一格的「方块 ID + 展示实体身份」快照发生变化
  （右键→回退植株、左键→方块被砸掉，两种都会变）才写盘；窗口内没变就丢弃 ——
  点空、被服务端驳回、拿错工具都不会被学进去。
- 学会后播报一条：「已学会特殊变种收法 ▸ 巨型菠萝 ▸ 左键破坏｜按服务器分开记，其它服务器不受影响」
  （用户担心的正是跨服污染，所以这句话直接写给他看）。

### ③ 执行：新增「左键破坏」通道（真实挖掘进度，不是零硬度秒破）

- **不能复用** `BlockPacketSender#breakBlock`（START+STOP 同 tick）：那条通道是给硬度 0 的作物 / 竹子用的，
  而巨型作物的载体是硬度 0.4 的原版方块（紫颂植株），服务端按 `delta × (已挖 tick + 1) ≥ 0.7` 校验，
  同 tick 的 STOP 会被直接驳回。
- 因此走「`sendBreakStart` → 等够所需 tick → `sendBreakStop`」，公式与秒破 / 自动挖矿同源
  （`requiredDigTicks`，另加 2 tick 余量抵发包延迟）；挖掘期间协调器把控制权留在这一格
  （`verify` 里 `executor.digInProgress()` 分支 → 直接回 `INTERACT`），不让 `MAX_RETRY=3` 把这一轮打断
  （否则每几刻重挖一次、永远挖不穿）。
- 任务重规划 / 停机 / 换世界时 `abortBreakDig()` 发 ABORT：服务端才不会一直记着「这个玩家在挖这一格」。
- 工具：破坏口径**不要求背包有锄头**（本服实测空手也能砸），有就换手（更快）；右键口径仍需金锄头。
- 收割验证完全复用现成判据（`crop.state() != SPECIAL && potStillPresent`），破坏后那格变空同样成立。

### ④ 兜底提示

默认口径（金锄头右键）连续收不动（`MAX_RETRY` 用满）时，每个作物提示一次：
「特殊变种收不动（本服口径未知）▸ 手持金锄头右键连点多次，这一格毫无变化｜出路：拿金锄头对着它左键砸一棵，
我记住后照做；口径按服务器分开保存，其它服照旧用右键」。右键服上右键一收就成功，永远不会看到这条。

## 三、验证

| 项 | 结果 |
| --- | --- |
| `.\gradlew.bat compileJava` | **EXIT=0** |
| Mixin 注入点签名 | 已用 `javap` 对 26.1.2 `MultiPlayerGameMode` 核对（两个方法签名逐字一致） |
| 实机验证 | **待用户复测**（客户端已带新代码重启） |

复测要点：
1. 拿金锄头左键砸一棵巨型菠萝 → 聊天出现「已学会特殊变种收法 ▸ 巨型菠萝 ▸ 左键破坏」；
2. 此后模块自己收巨型菠萝 = 先挖（约 8~12 tick）再砸掉，能收进背包；
3. 换到老服（右键口径）→ 模块照旧用金锄头右键，不会被上个服学到的左键口径影响
   （`StardewFarm/special-harvest/<服务器>/<指纹>.json` 各服各一份）；
4. 回本服后无需重学（存盘已生效）。
