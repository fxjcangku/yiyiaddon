# 复盘：选择器打开即展开第一个有内容的分组（名单型选择器不再「满屏空白」）

- 日期：2026-09-21
- 触发：用户实机截图「你看 我打开目标选择器就这样」——自动挖矿「保留白名单」选择器打开后，
  左栏只有一行折叠标题「原版物品 · 1505」，右栏「已选 0 / 无」，整块面板其余全是空白
- 结论：不是数据错（当前存档白名单本就是空的），是**默认收起**在「只分得出一组」的名单型选择器上
  表现为「打开什么都没有」；按用户选定改法（开窗即展开分组）改掉，改动只在 `SelectorScreen` 一处

## 一、现象与取证

| 检查项 | 结果 |
| --- | --- |
| 窗口/候选来源 | 通用选择器 `ui/screen/SelectorScreen`；候选由 `MiningTargetControls#openKeepSelector` 给出，走 `MiningRegistry.itemEntries()`（物品按命名空间分「原版物品 / 自定义物品」两组） |
| 为什么左栏只有一组 | 该环境物品注册表里没有非 `minecraft` 命名空间的物品 → 「自定义物品」组一条候选都没有；`buildColumn` 的分组骨架按「候选里出现过的分组」建立，零候选的组不生成标题（既有口径） |
| 为什么「已选 0」 | 当前存档作用域 `singleplayer_新的世界 (1)` 的 `keepWhitelist` 在 `run-26.1.2/config/module-state.json` 里确实是 `[]`（另一台服务器 `server_long.kkwmc.cn_25565` 那份是 `["minecraft:tnt"]`）。逐服隔离（第 236 条）工作正常 |
| 为什么一片空白 | 分组默认收起（第 196 条）＋ 只有一个组 ⇒ 收起后左栏无候选行、右栏无已选行，面板只剩标题行 |
| 有没有异常 | 运行日志无本模组相关异常（`SelectorScreen` 一帧正常绘制；同期日志里的 OpenGL/refmap 警告来自第三方模组） |

结论：**数据与逻辑都对，缺的是「打开就能看见候选」**——分组默认收起的初衷（压住上千项长候选，
第 195~196 条）在「只分得出一组」的名单型选择器上失效了。

## 二、用户裁定（2026-09-21）

> 选择器打开时默认展开有内容的分组（至少第一组），打开就能看见候选物品；搜索时行为不变。

## 三、改动（`ui/screen/SelectorScreen`，最小改动）

1. 新增 `expandFirstGroup(Set<String> selected)`：开窗时把**第一个有可见候选的分组**写进
   `expandedGroups`；两级结构（装备库那类「大类 → 品质」）时连它下面第一个有内容的子组一起展开。
   取「第一个可见条目的所属分组」即可，因为分组顺序 = 分组在候选表里首次出现的顺序，
   而排在第一个可见条目之前的分组里没有任何可见条目。
2. 新增 `expandedFirstGroup` 闸：**只做一次**。`rebuild()` 在搜索词变化、加减条目后都会重跑，
   没有这个闸的话用户手动收起的首组会被立刻顶开（等于收不起来）。
3. `rebuild()` 里在算完 `selected` 之后、铺两栏之前调用；写进 `expandedGroups` 后与手动展开
   共用一个集合，因此用户收起即生效，也不会与「过滤词非空一律展开」的搜索态打架。
4. 类注释（顶部「分组可折叠」那一段）与 `expandedGroups` 的字段注释同步改写，写明这次追加的口径。

**没有做的事**（避免过度改动）：没有把所有分组默认展开（那等于作废第 196 条，装备库那种上千项
候选会立刻铺成两百行并被 `MAX_ROWS` 截断）；没有改搜索态、折叠记忆、右栏默认展开等既有口径；
没有碰各调用方给出的候选与分组。

## 四、与规则的关系（待用户裁定是否修订）

第 196 条原文是「每个分类必须可折叠，**且默认收起**」。本次按用户 2026-09-21 裁定放宽为
「**首个有内容的分组**开窗自动展开，其余仍默认收起」，规则正本 `开发习惯.md` 暂未改动。
若确认长期口径，建议在第二十九章补一条追加说明（第 196 条 → 首组例外），以免后续智能体按旧条
把这段自动展开删回去。

## 五、验证

| 项 | 结果 |
| --- | --- |
| `.\gradlew build --console=plain -q` | **EXIT=0** |
| 实机验证 | **未实机**（本轮只做到编译通过；客户端已用新代码重新启动，等用户打开「保留白名单」复测：预期左栏首组摊开、直接列出候选物品，其余分组仍收起） |

复测要点：
1. 自动挖矿「目标选择」页 →「保留白名单」打开：左栏应直接列出「原版物品」里的物品（含贴图），
   而不是只剩一行折叠标题；
2. 手动点标题收起该组后，再输入搜索词、再加/减一条，收起状态应保持（不被顶开）；
3. 分组多的选择器（装备库、目标实体、村民交易）：只首组展开，其余仍是收起态。
