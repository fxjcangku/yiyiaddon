# 复盘：缺对象也能打开的功能开关（洒水器维护 / 自动浇灌 / 自动施肥 / 自动用药剂）

- 日期：2026-09-22
- 触发：用户实机反馈（两连问）：
  1. 「自检 我选了洒水器 但是我实际是没绑定洒水器的 然后呢 就启动了 这是 bug，我 .stardew 绑定洒水器都没输入」
  2. 「而且我还打开了洒水器维护，这些都没检测的，没选洒水器不给打开洒水器维护才对，弹窗 / 状态栏小框」
- 结论：**启动自检一次会话只跑一次，而设置开关本身没有任何前置校验**。进服之后再打开一个「缺对象」的
  开关（没选洒水器型号、没绑洒水器点位…），没有任何判据会拦它：模块照常运行、开关显示「已开启」，
  实际那一项只是空转（维护链拿不到型号也找不到点位）。玩家看到的是「开了却什么也没发生」，
  还得自己猜为什么。

## 一、为什么自检拦不住

`StardewStartupCheck#collectStartupProblems` 里其实**有**这条判据：

```java
if (module.settings().sprinklerMaintenance) {
    if (module.selections().sprinkler().selectedKeys().isEmpty()) missing.add("已开启洒水器维护，但未选择洒水器");
    ...
}
```

问题在于它只在**启动那一刻**跑（`onEnable` / `onGameJoined`，一次会话一次，见
`module.setStartupSelfCheckDone(true)`）。玩家的真实操作顺序是「进服 → 自检通过 → 进设置页打开
洒水器维护」，此后没有任何入口会重新校验 —— 于是「开着但缺对象」这个状态无人拦下。

## 二、改动

### ① `StardewRunPage#boolRow`：布尔设置行支持「打开前置条件」

新增重载 `boolRow(..., Supplier<String> blockReason)`：

- `blockReason` 在**打开（true）**时先问一次，返回非空原因就**拒绝写设置**（不写、不落盘；
  `SettingToggle` 完全由 getter 驱动，开关会停在原位，不会出现「视觉上打开了、值没变」）；
- **关闭（false）永远放行** —— 不让人因为一个缺项连关都关不掉。

### ② 四个开关各自的前置条件（与启动自检同一口径，缺什么就说什么）

| 开关 | 打开前必须满足 | 提示原文（缺项时） |
| --- | --- | --- |
| 洒水器维护 | 已选洒水器型号 **且** 已绑过洒水器点位（任意维度） | 还没选洒水器型号：先在「洒水器」选择器里勾选要维护的型号，再打开洒水器维护 / 还没绑定洒水器点位：对准洒水器实物绑一次点位 |
| 自动浇灌 | 已选水壶（下界盆浇岩浆、末地盆浇龙息时不需要，与自检一致） | 还没选水壶：先在「水壶」选择器里勾选要用的水壶，再打开自动浇灌 |
| 自动施肥 | 已选肥料 | 还没选肥料：先在「肥料」选择器里勾选要用的肥料，再打开自动施肥 |
| 自动用药剂 | 已选药剂 | 还没选药剂：先在「魔法药剂」选择器里勾选要用的药剂，再打开自动用药剂 |

「洒水器维护」这条按用户口径**同时**要型号与点位：只有型号没点位 = 没有维护对象（空转）；
只判任意维度（不全维度硬性要求），本维度够不够仍由启动自检报出——否则在没洒水器的维度里
压根打不开这个开关。

### ③ 拒绝时的反馈：原位面板 + 聊天记录

`refuse(设置名, 原因)`：
- `ConfirmPanelScreen.noticeInPlace("星露谷农场 · 无法打开「…」", "§7这个开关要先满足条件：", List.of(原因), 本页)`
  —— 点掉回到设置页，不退出控制台（与「区域换作物失败」同一套原位口径）；
- 同时 `statusReporter().critical(...)` 在聊天栏留一条，只发聊天容易被后续状态播报刷走
  （启动自检当初加面板就是这个原因，「弹窗 + 状态栏」两处都给）。

## 三、验证

| 项 | 结果 |
| --- | --- |
| `.\gradlew.bat compileJava` | **EXIT=0** |
| 实机验证 | **已通过**（用户 2026-09-22「修复了 记录一下」） |

复测要点：
1. 没选洒水器型号时点「洒水器维护」→ 开关不动、弹面板说明「还没选洒水器型号」；
2. 选了型号但一台点位都没绑 → 同样拒绝，提示改为「还没绑定洒水器点位」；
3. 选好型号 + 绑一台点位 → 可以打开；从「开」切到「关」任何时候都不拦；
4. 自动浇灌 / 自动施肥 / 自动用药剂 同上（下界盆、末地盆时「自动浇灌」不需要选水壶）。
