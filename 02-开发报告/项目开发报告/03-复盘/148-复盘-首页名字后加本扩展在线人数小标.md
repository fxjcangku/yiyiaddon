# 148-复盘-首页名字后加本扩展在线人数小标

## 一、需求与拍板

用户原话（四条，逐轮收敛）：

1. 截图首页账户条（`正版：yiyijia`）后问：「这里旁边你可以帮我设计一个 当然使用扩展实时人数吗？」
2. 「名字后面」
3. 「改成累计使用人数」（中间一度按累计值做了一版）
4. 「不不不 是当前在线人数 你误会了 然后下面的使用人数改成累计使用人数」

**最终口径（两处，别混）：**

| 位置 | 内容 | 数据源 |
| --- | --- | --- |
| 玩家名后面那枚小标 | **当前在线人数**（本扩展此刻在线，实时，会上下浮动） | `HomeStats#onlineUsers()` |
| 数据格第二格 | 标签由「使用人数」改为「**累计使用人数**」（历史总数，只增不减） | `HomeStats#totalUsers()` |

该小标**旧项目首页没有**，属用户点名的界面新增（第 165 条：改动先经用户同意 —— 上述原话即同意依据）。
文案不是新造：小标口径来自旧项目 `26.1.2/.../userstats/UserStatsModule.java:417`「当前有 N 位玩家在线」。

## 四、设计与口径

1. **小标文案**「在线 N 人」；圆点与文字同色系：有数据时在线绿（`COLOR_GOOD`），未取到数据时「在线 --」+
   灰点（与数据格 `--` 占位同一口径，不伪造 0）。悬停给完整口径：「当前使用该扩展的玩家 / 当前有 N 位玩家在线」。
2. **刷新节奏**：世界内跟心跳（后端写库节流 30 秒一次回带），主菜单走 `/api/stats` 轮询兜底 ——
   与「累计使用人数」同源同节奏，客户端不额外发请求。
3. **排版不会越界**：名字先按「留给小标的位置」省略（`Math.max(60, innerRight - ONLINE_GAP - chipW - nameX)`），
   再用 `Math.min(nameEnd + ONLINE_GAP, innerRight - chipW)` 收口；绘制与悬停命中同一组坐标。
4. **两处口径不混**：小标是实时在线，数据格是累计总数，标签写全「累计使用人数」就是为了让两者一眼可分。

## 六、影响面

- 用户可见新增/变更文本：「在线 N 人」、「在线 --」、数据格标签「累计使用人数」（中文）/「Total Users」（英文）、
  悬停两行文案。
- 落盘结构、网络请求数量、后端接口：**零变化**。
- 卡片几何不变（账户条内绘制，未改 `ACCOUNT_H` / `dataCardH()`）。
- `formatCount`（千分位）为数据格与小标共用一份；`drawMetricRow` 的标签省略只影响超宽标签，正常标签无变化。
