# 182 - 复盘：管理员消息改为 HUD 顶部横幅（停留 10 秒）

日期：2026-09-21
分支：`master` + `port/26.2`
验证：两线 `compileJava` EXIT=0；**未实机验证**（需要真实客户端 + 后台发一条消息）

## 一、用户指令与改法

用户原话：「[管理员] hihi (使用 .回复 <内容> 回复) 这个回复 能不能做成 ui 弹窗 状态栏那种 这个停留久一点10秒」。

改动前：管理员消息在 {@code ChatService#pollNow} 里走 `ClientChat.raw`，聊天栏出一行
`§b[管理员] §f<正文> §8(使用 .回复 <内容> 回复)` —— 混在服务器刷屏里一眼看不见，还拖着一串括号说明。

改动后：管理员消息画成 **HUD 顶部横幅**（状态栏位置、玻璃材质），三层排布
（强调色圆点 + 「管理员消息」标题 / 正文 / 「使用 .回复 <内容> 回复」提示），停留 10 秒后淡出；
玩家之间的跨服聊天照旧进聊天栏。

| 文件 | 改动 |
| --- | --- |
| `ui/render/HudBanner.java`（新建） | 横幅的排队、计时与绘制；材质/取色与 `TooltipLayer` 顶部提示同源 |
| `mixin/client/GuiRendererMixin.java` | 在 `WorldOverlay.renderOverlay()` 之后调 `HudBanner.render()` |
| `service/ChatService.java` | `fromAdmin` 走 `HudBanner.show(...)`；删掉聊天栏里那条管理员专用渲染分支 |
| `YiyiAddonClient.java` | 断线订阅里补 `HudBanner.clear()` |
| `ui/render/MinecraftText.java` | 折行从 `TooltipLayer` 私有方法收敛为 `MinecraftText#wrap(text, size, maxWidth)`（第 169 条：单一实现） |
| `ui/render/TooltipLayer.java` | 私有 `wrap` 改为委托，行为不变 |

## 二、几个必须写下来的口径

1. **画布走现成的 HUD 路径**：`GuiRenderer#render` 的 HEAD 是全项目自绘内容的统一时机
   （世界叠加层也在这里取画布），多注册一个 HUD 回调只会多一份 GL 状态与画布归属的坑。
   `SkiaGlBackend#begin` 已按 GUI 缩放做过变换，因此横幅坐标一律按 **GUI 逻辑坐标**算。
2. **计时从真正上屏那一帧开始**：面板（`SkiaScreen` 子类）开着时整个 HUD 被盖住、画了也看不见，
   此时既不绘制也不计时，面板一关才开始十秒 —— 否则玩家一开面板就等于把消息吞了。
3. **正文超长先缩字号再折行**：字号自 13 起，折行超过 3 行才逐 0.5 缩到 9 为止，短消息始终保持 13。
   300 字的消息因此也能完整显示（宁可框变高，不截断、不省略）。
4. **只画在 HUD 层**（世界之上、原版 GUI 之下）：与 ESP 字牌同一层，保证不被后面的世界内容压住。
5. **材质与主题联动**：投影 / 霜化 / 环境光 / 高光内描边四项与 `TooltipLayer` 的顶部提示同参，
   取色全走 `ClickGuiThemeColors`，换主题当帧生效。
6. **管理员消息不再进聊天栏**（用户的界面要求）——历史记录里没有这一行；
   需要留档的话把 `ChatService` 那处 `continue` 去掉即可恢复「横幅 + 聊天栏」双通道。

## 三、26.2 线同步（cherry-pick）

`git cherry-pick 2da55c9` → `fc2af8a`，**唯一冲突在 `GuiRendererMixin` 的导入块**：
本线（26.2）的 `GuiRenderer#render` 去掉了雾缓冲参数，注入方法只收 `CallbackInfo`，
因此**本线没有 `com.mojang.blaze3d.buffers.GpuBufferSlice` 这一行导入**。
解法即「删掉那行导入、保留 `HudBanner` 导入」，方法体与本线原有的注释一字未动；
解完 `compileJava` EXIT=0。这正是第 136 号复盘第三节第 4 行登记过的那条口径
（`net.minecraft.client.gui.GuiRenderer#render` 在 26.2 去掉了参数），不是新差异，无需登记。
