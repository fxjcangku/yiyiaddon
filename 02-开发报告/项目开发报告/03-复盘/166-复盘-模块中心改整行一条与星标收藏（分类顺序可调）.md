# 166-复盘-模块中心改整行一条与星标收藏（分类顺序可调）

## 一、用户原话与诉求

> 「C对对对模块中心 重新排序能不能做成上下开关的的你能懂我的意思吗 现在是左右的 给我个方案」
> → 「分类顺序自己调 可以吗？ 然后取消右键收藏 改成🌟收藏 不要emoji 就是一个收藏键 就行
>    然后添加到收藏模块里面 靠你了 你帮我设计一套好看能看清全部字没有....的」
> → 「按照自动附魔点位成熟代码 都写上这些模块」阶段的收尾口径，本条为模块中心的界面定稿。

四项要求：

1. 模块中心展开后的模块**不要横向并排**，改成上下一条一条；
2. 名字必须**完整可读，整页不出现「…」**；
3. **取消右键收藏**，改成每行一枚**星标收藏键**（不要 Emoji），收藏的进「常用模块」；
4. **分类顺序让玩家自己调**。

## 二、取证（先查清「为什么会有省略号」再动手）

| 现状 | 取证位置 | 结论 |
| --- | --- | --- |
| 展开后横向并排 | `ModuleCenterPage.gridColumns()` + `ModuleRow.drawCell` | 网格按「最宽模块名 + 状态徽章 + 内边距」反推列数（面板 740 时最多 2 列），一格里只剩「图标 + 名称 + 状态」 |
| 出现「自动图书…」 | `ModuleRow.drawCell` 里名称按可用宽 `ellipsize` | 单元可用宽约 200，最长名「自动图书管理员」放不下 → 截断 |
| 右键才能收藏 | `ModuleCenterPage.onClick` 的 `GLFW_MOUSE_BUTTON_RIGHT` 分支 | 右键**零视觉提示**，装完没人知道能这么用；`FAVORITES_CATEGORY` 的描述里写着用法，但它只在分类入口行显示，收藏块自己不显示 |
| 分类顺序写死 | `CategoryRegistry` 注册时的 `order` 权重 | 玩家无法调整，只能按代码顺序看 |

## 三、改动清单

### 1. `ui/component/ModuleRow.java`

- **删**：`drawCell`（网格单元）、`draw`（无分类兜底整行）、`nameWidth` / `cellFixedWidth`（只服务网格列宽反推）——本轮之后无引用。
- **新增** `drawRow(...)`：整行一条 = 图标 + 模块名 + 描述 + **星标** + 状态 + 进入箭头。
  - **名字优先完整、描述放不下就不画**：名称先按可用宽量一次，放得下就整段画；剩下的宽度才给描述，
    描述放不下时整段交给悬停浮层 → 整页不出现省略号（用户要求 2）。
  - 星标：已收藏 = 强调色，未收藏 = 弱色，悬停更亮 + 垫一层淡底。收藏态用**颜色**表达，
    不换另一枚字形（项目验真过的星形只有 `\uE838` 一枚，第 140 条）。
- **新增** `starCenterX / starCenterY / STAR_HIT`：星标中心距行右边缘是**固定值**（`STAR_RIGHT_INSET = 96`），
  不跟着状态徽章文字宽度走 —— 绘制与点击判定各算一次几何，依赖徽章宽度早晚错位（第 169 条）。
- **口径变更**：`drawRow` / `drawEntry` 的 `x、w` 改为「这一行的**最终**矩形」，左侧缩进由调用方几何给出，
  组件不再自行缩进（否则绘制比命中框多缩一次 14px，点左边会点空）。

### 2. `ui/page/ModuleCenterPage.java`

- **一行一个**：删掉网格排布（`ensureLayout` / `gridColumns` / `minCellWidth` / `slotOf` / `colOf` / `colsOf` /
  `MIN_CELL_W` / `FALLBACK_CONTENT_W` / `resetLayout`），行宽只剩两种取值（分类头不缩进、模块行缩进 14），
  几何由 `cardWidth` / `cardX` / `cardY` / `contentHeight` / `indexAt` 一组钩子给出，绘制/悬停/点击/总高度同源。
- **星标收藏**：`onClick` 先判星标小块（命中框与绘制同源），命中则收藏/取消收藏 + 立即落盘 + 重建清单
  （顶部「常用」块与首页「常用模块」当场反映）；其余区域仍交给基类进模块页。
- **删除右键收藏**：右键在本页不再有任何行为（用户要求 3）。
- **分类调序**：分类头右侧加 ▲ / ▼（`\uE5C7` / `\uE5C5`），点一下该分类上移 / 下移一位，
  顺序写 `AddonConfig.moduleCategoryOrder`，重启保留；首位不画 ▲、末位不画 ▼（**位置照旧占住**，
  标题与模块数不会左右跳，也不存在「点了没反应」的死按钮）。
- **吸顶条**：滚动吸顶的分类头**不画** ▲▼，并且命中到吸顶条时只做展开 / 收起
  —— 同一块地方画了什么就只允许点什么，避免点到一个看不见的按钮（第 169 条）。
- **排版同源**：分类头一行的排版（标题截断结果、▲▼ 左边界、模块数文案与右边界）收进
  `headerLayout(...)` 一份结果，绘制与命中共用。

### 3. `config/AddonConfig.java`

- 新增 `moduleCategoryOrder`（`;` 分隔的分类 id，读写各一行）：只影响**模块中心的显示顺序**，
  文件里没记到的分类按注册表权重补在末尾 —— 版本更新新增分类既不会丢，也不会打乱玩家排好的顺序。

## 九、分类拖动换位（同日追加，用户「可以拖拉排序吗？」）

在 ▲▼ 之外补上**按住分类头上下拖动**的换位手势（用户问的就是这个），两套手势改同一份顺序、
同一份落盘字段 `AddonConfig#moduleCategoryOrder`：

- **手势分工**（`ModuleCenterPage`）：分类头按下时只记状态（分类 id / 指针 y / 按下前的顺序快照），
  纵向移动超过 `DRAG_THRESHOLD = 4` 像素才算「拖动」；**展开 / 收起移到松手时判定** ——
  按下即开合的话，一动鼠标会先把分类展开，看着像误触。
- **实时换位**：拖动过程中把被拖的分类插到指针所在分类的位次上并立刻重建清单，那一行始终跟在指针下，
  不必额外画「拖影」；落盘只在松手时写一次。
- **误触保护**：不足阈值 → 什么都不改（松手仍是开合）；手势被取消（`cancelPress`，例如按下期间界面被关掉）
  → 用按下前的顺序快照还原，半途的顺序既不进配置也不留在内存（第 249 条）。
- **按住反馈**：被按住的分类头按「悬停满值」绘制，一眼能看出正抓着哪一行。
- 分类内的模块顺序、模块的所属分类都**没有**开放拖动：模块归属是注册时的常量（第 169 条同源口径），
  要开放得先加一层「运行时覆盖表」，等用户点名再做。

## 十、行位移动画（同日追加，用户「动画有吗」）

原先换位是「瞬间跳位」，只有悬停渐变与按下缩放两档反馈。本轮补上行位移动画，覆盖三处：

- **拖动换位**：被拖的分类滑向新位次，被挤开的行反方向让位；
- **展开分类**：新出现的模块行从上方 14 像素滑入，其下的行同步下移让位；
- **收起分类**：其下的行上移补位（被收起的模块行本身直接消失，没有出场动画 —— 要做需要保留幽灵行，代价大于收益）。

实现（`ModuleCenterPage`）：

- 每行一个 {@link Spring}（临界阻尼 {@code ROW_SLIDE_SETTLE = 0.22s}），状态存「相对静态槽位的偏移」，
  **目标恒为 0**。每次 `rebuildRows()` 用重建前的行位次做快照 `before` 播种：老行按位次差起步、
  新行按 `-ROW_INSERT_LIFT` 起步；静态位次没变的行不重置弹簧（拖动时清单会反复重建，重置会把手感打断成跳变）。
- 几何严格单源：`cardY`（绘制）与 `indexAt`（命中）都加同一个 `rowShiftOf(index)`，
  画面滑动时命中框跟着滑，不会出现「看着在这里、点到的却是别行」（第 118 条同源口径）。
- 行标识按内容取（模块 id / 分类 id + 是否页面入口），换位与展开后仍认得出是同一行。

**踩坑与修复（实机才暴露）**：`Spring#set(value)` 是「直接落到某个值」，它**把目标也设成同一个数**，
只调 `set(offset)` 会让所有行永远停在偏移上（实测所有行卡在 -14 不动，截图里行与分类头重叠）。
改为 `set(offset)` + `setTarget(0)` 两步（抽成 `startRowShift`）后正常收敛。

实机验证（`.\gradlew build` EXIT=0 → `runClient`）：展开「自动化」后 7 行滑入、其余分类下移让位，
停定后与静态槽位严格对齐（无残留偏移）；把「视觉」拖到第三位，列表停定为
星露谷 → 视觉 → 自动化 → 工具 → 辅助 → 战斗，配置写成
`moduleCategoryOrder = "stardew;visuals;automation;utility;assist;combat"`。
