# Minecraft 动态展示与混淆 Beta 公开发布

## 用户授权与结果

用户要求将上一版通用科技风改为更专业的 Minecraft 风格，随后要求动图，并明确授权“同时发布 Beta 测试版，混淆”。该后续授权取代报告 124 的暂不发布状态。

已更新 [公开首页](https://github.com/fxjcangku/yiyiaddon)，发布 [v1.0-beta1](https://github.com/fxjcangku/yiyiaddon/releases/tag/v1.0-beta1)，标记为 Pre-release，未设置为稳定版 Latest。首页提交为 `2aabfc68161c046552b4f8457a8fa7f92fab094e`。

## 展示设计

使用 imagegen 生成方块农场与矿洞场景插画，源图保存在 `06-发布页面/仓库首页/展示资源/方块世界场景.png`。将自绘点阵标题与代码驱动的轻微光点、薄雾、高光图层组合成浏览器帧，再通过 sharp 编码为 GIF。没有将示意图冒充实际游戏截图。

动态封面：1120×520，40 帧，每帧 125 毫秒，5 秒循环，421,061 字节；同时提供静态 PNG。README 与 Release 正文均显示动态封面，README 保留静态封面链接。本地预览使用苔绿、木石色与物品栏边框，GitHub 平台自身导航及皮肤不受 README 控制。

本轮保留详细模块介绍；移除通用科技风主封面引用。生成工具为 `工具/制作动态封面.cjs`，预览样式独立放在 `工具/预览样式.css`，`工具/生成预览.mjs` 从同源 Markdown 生成 HTML。

## 公开范围与仓库隔离

在 `build/public-release-repo/` 单独检出原公开 master，仅提交 README 和四个展示资源，不向 origin 推送当前源码工作区或其历史。公开仓库既有 LICENSE、CREDITS 保留。源码仓库没有本轮提交或推送。新项目仍为独立 Fabric 客户端模组，旧项目未修改。

GitHub API 核对：`isPrerelease=true`、`isDraft=false`，仅两个用户上传附件；自动生成的 Source code 压缩包属于展示仓库快照，不是模组安装包。已在说明中区分。没有上传映射、反编译归档、开发报告、插画源文件或测试日志。

## 下一阶段开发规划

### 一、下一阶段目标

收集 Beta 的实际功能与性能反馈，优先覆盖比赛演示路径。

### 二、执行原因

启动验证与自动检查不能代替每个模块在真实场景中的运行。

### 三、前置条件检查

Beta 已可下载，映射与校验值齐全；需要使用对应版本并保留复现步骤、环境和相关日志。

### 四、任务拆分

1. 目标：验证核心功能；涉及目录：独立测试实例；影响范围：测试存档和配置；预计修改内容：记录星露谷、挖矿、仓储等流程，发现证据明确的问题后再定点修复。
2. 目标：后续版本发布；涉及目录：发布展示文件与混淆产物；影响范围：公开附件；预计修改内容：依据测试结果更新版本，使用新标签和新映射，不静默替换本次已公开二进制。

### 五、验收标准

构建与启动已通过、展示及发布报告完成、没有新增旧框架依赖；完整功能仍待实际验收。未来发布需再次核对实际上传包摘要与测试记录。

### 六、禁止事项

禁止公开源码或映射，禁止把 Beta 当稳定版，禁止把概念场景当实机截图，禁止将本轮启动结论套用到别的摘要。
