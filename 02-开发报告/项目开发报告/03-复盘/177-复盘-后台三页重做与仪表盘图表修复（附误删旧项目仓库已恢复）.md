## 二、三页重做

`.chips/.chip`（在线玩家胶囊）、`.tl`（时间线）、`.sw/.toggle`（iOS 开关）、`.empty`、`.hint`；
删除已无引用的 `.tab-btn`、`.msg-row/.msg-meta/.msg-text`。

### 1) 聊天消息 → 跨服聊天控制台

原来是「玩家聊天记录 / 管理消息 / 设置」三段平铺列表，且每行前面的正版/离线徽标取的是
`m.is_premium`——而 `/api/messages/history` 根本不返回该字段，**所有行永远显示"离线"**。

重做为：

- 分段：`跨服频道(n) / 私信(n) / 清理`；
- 跨服频道：顶部「跨服在线」胶囊（皮肤头像 + 名字 + 延迟，取自 `/api/admin/players`，后端 `is_online`
  已按心跳超时计算）+ 频道气泡流（管理员在右侧蓝色、玩家在左侧灰色）+ iOS 输入条，
  发送走 `/api/messages/send`（`target_uuid` 为空 = 广播，与玩家公屏同一条频道）；
- 私信：收件人下拉 + 双向气泡（玩家侧标注"→ 管理员"，提示玩家可用 `.回复` 回）；
- 清理：保留全量清空按钮并写明「无定时任务、不按保留天数」；
- 消息流 5 秒增量轮询：只在消息 id 变化时重绘消息容器，**不整页重绘**，输入框里的文字与焦点不受影响；
  用户上翻看旧消息时不强制贴底。离开聊天页即停轮询。

### 2) 安全监控

原来是「正版/指令/异常」三段纯列表。重做为：KPI 指标行（正版账号 / 离线账号 / 疑似 VPN / 指令记录 /
崩溃与异常）+ 分段：

- 账号安全：正版账号明细（皮肤、正版与疑似 VPN 徽标、微软账户 + XUID、所在服务器、在线状态），
  右上角「重新校验」保留（触发 Mojang 复验）；
- 指令记录：时间线样式，指令名单等宽字体 + 玩家 / 分类 / 相对时间；
- 崩溃与异常：崩溃按次数聚合展示，异常行为带高危/中危/低危徽标（沿用 `fmtSeverity` 汉化）。

### 3) 系统设置

原来是「说明长文 + 键值列表 + 手填 Key/Value」。重做为：

- **远程开关**：6 个真实生效的键直接给 iOS 开关，一点即存（`POST /api/admin/config`），
  失败回滚 UI；开关判定与客户端 `RemoteFlags.enabled` 同口径（键没下发或值不是 `false` 都算开）；
- 其他配置：只列 6 个已知键以外的自定义键，带删除（走真 `DELETE`）；
- 添加配置：精简表单；
- 键的中文名与说明逐字对应客户端实际作用点，不再宣传无效配置项。

## 三、仪表盘两个真缺陷（用户报的"数字是斜的"）

1. **活跃趋势的 x 轴日期被 Chart.js 自动旋转**成斜排（默认 `maxRotation:50`）→ 明令
   `maxRotation:0/minRotation:0`，并限制 `maxTicksLimit` 与精度，日期改为 `9/8` 短格式；
2. **国家分布环形图塌缩**：画布用 `style="max-height:280px"` 且父容器无固定高度，
   `maintainAspectRatio:false` 下高度自算成约 30px（截图里缩成左上角一个小圈）→
   改用固定高度容器 `.chart-box`；
3. 顺带修掉一个每次轮询都在泄漏的缺陷：仪表盘每 5 秒重建卡片，`new Chart()` 却从不解绑 →
   每次渲染前 `destroy()` 旧实例。
