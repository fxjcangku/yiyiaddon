# 仓库展示页设计与功能介绍草稿

## 本轮交付

用户要求先设计专业的仓库发布展示页，详细介绍星露谷、自动挖矿等功能，待游戏测试通过后再发布。本轮交付全部位于 `06-发布页面/`，没有提交、推送、创建远程草稿或上传发布附件。

设计采用深色青绿封面、几何方块插画、功能概览、专题图与分模块说明。新增内容包括：

- `仓库首页/README.md`：用于公开仓库的中文正文，包含星露谷、挖矿、箱子、原版农场、附魔和交易专题，以及安装、版本状态、反馈和致谢。
- `仓库首页/展示资源/`：作品封面、农场功能图、挖矿功能图三个 SVG；全部为概念插画，不冒充实机截图。
- `版本说明草稿.md`：Release 正文与待验收状态，不预填未确认的附件摘要。
- `页面预览.html`：同源 Markdown 生成的本地深浅主题预览，附章节导航、版本正文切换与折叠步骤。
- `首页效果预览.png`：浏览器实际渲染截图。
- `工具/生成预览.mjs`、`使用说明.md`：预览生成方式和后续发布文件范围。

新项目是独立 Fabric 客户端模组，旧项目只作为历史参考，本轮未修改任何模组代码或旧项目文件。保留现有 LICENSE、CREDITS，不宣称完全无第三方贡献。其他并行任务的业务修改未回退。

## 内容取证

公开仓库 [fxjcangku/yiyiaddon](https://github.com/fxjcangku/yiyiaddon) 当前主页为简短发布说明，默认分支 master。本轮基于该定位准备替换用草稿。

功能信息核对当前源码：`AddonModules#createModules` 的注册列表；`StardewFarmModule#helpContent` 的资源准备、六页签、种植与后勤；`AutoMinerPage` 的流程和白名单要求；自动箱子控制台及其运行、取物和保护页；`AutoFarmHelpContent`；`EnchantPage`、`EnchantConsoleScreen`；`AutoVillagerTradeHelpContent`、`AutoLibrarianHelpContent`。

页面突出用户能配置和使用的能力，不公开源码结构或加固实现。未将帮助中明确留白的种子预测挖矿、假矿检测当可用功能。星露谷模块明确指 Minecraft 服务器对应玩法，不混称独立游戏的插件。保留挖矿丢弃规则和服务器配置前提，避免展示文案误导使用。

环境来自 `gradle.properties`、`fabric.mod.json`、`build.gradle`：Minecraft 26.1.2，Java 25，Loader 0.19.5 起，当前测试 Fabric API 0.155.2+26.1.2。当前包仅随附 Windows x64/ARM64 原生组件，因此不宣称其他系统已支持或所有 Windows 架构均已实测。
