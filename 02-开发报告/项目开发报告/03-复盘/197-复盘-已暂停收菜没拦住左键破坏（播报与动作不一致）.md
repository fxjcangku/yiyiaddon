# 复盘：「已暂停收菜」没拦住左键破坏（播报与动作不一致）

- 日期：2026-09-22
- 触发：用户实机 ——「产物箱没有可用空间 / 已停止 ▶ 还是继续收菜 你看日志」「然后背包满了 还是继续收菜
  但是又不破坏 是不是我背包的物品没到 64 格 不算满？不是检测背包没格子就暂停吗」
- 取证：本地开发客户端 `run-26.1.2/logs/`（会话轮转档 `2026-09-21-5/6/7.log.gz` 与 `latest.log`）

## 一、先纠正一条口径（回应用户那一问）

「背包满」的判据从来不是「64 格」也不是「物品堆叠数」，而是**主背包 36 格（快捷栏 + 背包，
`Inventory` 下标 0~35）里有几格是空的**，一个空格都没有才算满（195 已定的边界
`StardewInventoryService.MAIN_SLOTS`；护甲 4 格与副手 1 格不算 —— 它们是
`getContainerSize()` 的 41 里有、主背包里没有的 5 格）。

日志证明这条判据本身是好的：

```
[23:36:03] [星露谷农场]产物箱没有空间，已暂停收菜
[23:36:04] [星露谷农场]背包已满，已暂停收菜 / 拾取        ← 两条闸都真的触发了
[23:36:05] [星露谷] 破坏 开始挖掘 目标=4796,85,-5601 …    ← 它照样动手了
```

而且此后再没有一条「收割交互」日志 —— 右键采收确实被拦住了。**用户看到的「还在收」并不是右键采收，
而是同一句「已暂停收菜」下面模块仍在砸方块**（清枯苗 / 清错位 / 清杂物的左键破坏，特殊变种的左键
收割口径同理）。

## 二、成因：两条「满了」的闸只挂在右键采收那一条分支上

`StardewTaskPlanner#resolveTask` 里原先是这么写的：

```java
if ((state == MATURE || state == SPECIAL) && bagFullBlocksHarvest()) return null;
if ((state == MATURE || state == SPECIAL) && outputBoxFullBlocksHarvest()) return null;
```

只认「成熟 / 特殊变种」两种状态。而左键破坏这一类走的是另外三条分支：

| 状态 | 任务 | 原先是否受两条闸约束 |
| --- | --- | --- |
| `DEAD` | 清枯苗 `CLEAR_DEAD` | 否 |
| 分区错位 | 清错位 `CLEAR_MISMATCH` | 否（在更靠前的一行直接 `return`） |
| `UNKNOWN`（盆上杂物） | 清杂物 `CLEAR_JUNK` | 否 |
| `SPECIAL` + 学到的左键口径 | 收割（`doSpecialHarvest → breakAt`） | 是（走 `SPECIAL` 那一支） |

破坏与右键采收的**共同点**是都会把东西拿到手里（打掉方块 = 掉落物），所以「背包满 / 卸不出去」时
破坏同样该停；只有浇水 / 播种 / 施肥不产出新物品，才该照常跑。这是「少了半条判据」，不是设计取舍。

## 三、处置：两条闸提到一处，按「会不会拿到东西」统一判定

- 新增 `TaskType#breaksPlant()`（清枯苗 / 清错位 / 清杂物三合一），执行层
  `StardewFarmExecutor#sendBatchActions` 原先自己抄了一遍同样三连，改为共用这一份（第 169 条）。
- `resolveTask` 里两条闸合成一句，判据换成「这一步会不会把东西拿到手里」：

```java
if (harvestsOrBreaks(state, cell) && storageFullHalts()) return null;   // 成熟 / 特殊 / 枯死 / 盆上杂物
```

  `storageFullHalts()` = `bagFullBlocksHarvest() || outputBoxFullBlocksHarvest()`（短路：背包已经满了
  就没必要再播箱子那条；两条同时成立时聊天栏只留一条，信息由「背包已满…｜产物箱没有空间，成品卸不出去」
  这一行说清）。错位那一支是提前 `return` 的，单独补上同一条闸。
- 浇水 / 播种 / 施肥 / 补水 / 洒水器不受影响（不产出新物品）。

## 四、验证

| 项 | 结果 |
| --- | --- |
| `.\gradlew build --console=plain -q` | **EXIT=0** |
| 背包满 / 产物箱满 | 右键采收、特殊变种收割、清枯苗 / 清错位 / 清杂物一律不派发；聊天栏只留一条结论 |
| 浇水 / 播种 / 施肥 | 照旧执行（不产出新物品，满仓时也正是玩家最需要的维护动作） |
| 实机复测 | **未实机**（用户重启客户端后按同一场景复测：满仓 + 田里有杂物 / 枯苗，观察是否还在砸方块） |
