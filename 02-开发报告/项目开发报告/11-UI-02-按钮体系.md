## 一、本报告范围

本次只做**按钮类组件**：按钮本体、图标按钮、横向按钮行，以及让按钮具备悬停反馈所需的控件协议扩展。

不做的事：不改主题、不改页面结构、不动业务逻辑、不做 `ItemIconCache`（属 UI-03）。

---

## 二、设计目标

1. **一个按钮类覆盖全部用法**：旧项目出现过的按钮排布（满宽单按钮、等宽多按钮、筛选按钮、行内操作按钮、危险按钮）都能用同一套 API 表达。
2. **三态完整**：旧项目每个控件都有 `normal / hovered / pressed` 三态，新按钮必须补齐——此前只有按压缩放，没有悬停底色变化。
3. **外观自研**：不照搬旧项目外观，视觉按本项目设计语言（圆角、间距、层级提亮）。
4. **文案与作用照旧项目**：按钮组件只负责「长什么样、怎么响应」，文字与点击作用由调用方传入，调用方照旧项目原文填写。

## 三、组件清单

| 组件 | 路径 | 协议 | 用途 |
| --- | --- | --- | --- |
| `Button` | `ui/widget/Button.java` | `SettingWidget` | 全部按钮的唯一实现 |
| `IconButton` | `ui/widget/IconButton.java` | `SettingWidget` | 方形图标按钮（行内操作、加减、关闭） |
| `ButtonRow` | `ui/component/ButtonRow.java` | `CompactElement` | 横向按钮行（满宽单按钮 / 等宽多按钮 / 混排） |

配套改动：

| 文件 | 改动 |
| --- | --- |
| `ui/widget/SettingWidget.java` | 新增 `hover(mouseX, mouseY, x, y, width)` 默认空实现，用于注入悬停位置 |
| `ui/component/CompactRow.java` | 绘制控件前转发 `hover(...)` |
| `ui/widget/SettingModule.java` | 主控件 / 子控件 / 孙控件三处绘制前转发 `hover(...)` |

**悬停协议说明**：`SettingWidget` 的 `draw(canvas, x, y, alpha)` 没有鼠标参数，因此新增 `hover(...)` 由宿主在绘制前调用。`CompactRow`、`SettingModule`、`ButtonRow` 已自动转发，业务代码无需关心。

## 四、`Button` 规格

### 4.1 变体

| 变体 | 常态底色 | 常态文字 | 悬停 | 用途 |
| --- | --- | --- | --- | --- |
| `PRIMARY`（`primary()`） | `accent` | `accentOn` | 底色混白 10% | 主操作：确认、保存、添加、查找 |
| `SECONDARY`（`secondary()`，默认） | `buttonBackground` | `buttonText` | 底色混入 `accent` 14% | 次要操作：刷新、清理、取消、返回、输出 |
| `DANGER`（`danger()`） | `buttonBackground` | `dangerHoverText`（红） | 底色转 `dangerHoverBackground`，文字红 | 删除、清空、移除 |
| `GHOST`（`ghost()`） | 无底色 | `secondaryText` | 浮出 `hoverBackground` | 极轻操作，密集区域 |

### 4.2 尺寸

| 档位 | 高度 | 字号 | 水平内边距 | 圆角 |
| --- | --- | --- | --- | --- |
| `SMALL`（`small()`） | 20 | 10 | 10 | 6 |
| `MEDIUM`（默认） | 24 | 11 | 14 | 8 |
| `LARGE`（`large()`） | 28 | 12 | 16 | 9 |

`MEDIUM` 与 `SettingTextBox` / `SettingNumberBox` 同高，可直接与输入类控件同行；`LARGE` 与 `SettingSegmented` / `BackButton` 同高。

### 4.3 宽度

| 模式 | 方式 | 说明 |
| --- | --- | --- |
| 内容自适应（默认） | 不设置 | 宽 = 内边距 × 2 + 文字宽（+ 图标宽与间距），最窄不小于 2 倍高 |
| 固定宽 | `width(px)` | 显式指定宽度 |
| 满宽 / 等宽平分 | 交给 `ButtonRow` | `ButtonRow` 按行宽平分后调用 `drawAt` / `onClickAt` 传入实际宽度 |

### 4.4 状态

| 状态 | 设置方式 | 表现 |
| --- | --- | --- |
| 选中 | `selected(Supplier<Boolean>)` | 按 `accent` 实底 + `accentOn` 文字渲染，用于筛选 / 切换按钮 |
| 禁用 | `disabledWhen(Supplier<Boolean>)` | 整体透明度 × 0.4，不响应点击、不显示悬停 |
| 悬停 | 宿主自动转发 | 底色过渡，时间常数 `14`（约 0.14s） |
| 按下 | 自动 | `PressState` 缩放至 0.97，回弹用 `easeOutBack` |

主操作与选中态额外叠一层 `GlassPanel.rim` 高光，与卡片层级一致。

### 4.5 图标

`icon(码点)` 设置前缀图标，使用 Material Symbols 字体，与文字之间固定 6px 间距；图标与文字作为整体在按钮内居中。

### 4.6 常用 API

```java
new Button("刷新", () -> doRefresh())                 // 默认 SECONDARY / MEDIUM / 内容自适应
new Button("确认清空", this::confirm).danger()        // 危险变体
new Button("保存", this::save).primary()              // 主操作
new Button("更多管理", this::openManage).icon("\uE5CC")  // 带右箭头图标
new Button(() -> selectedText(), this::pick)
        .selected(this::isPicked)                     // 选中态随状态变化
new Button("应用", this::apply).disabledWhen(() -> !dirty)
```

## 五、`IconButton` 规格

| 项 | 说明 |
| --- | --- |
| 形状 | 圆角方形，圆角 = 边长 × 0.34 |
| 边长 | 默认 24，`size(px)` 可调 |
| 图标字号 | 默认边长 × 0.58，`glyphSize(px)` 可调 |
| 默认形态 | **幽灵**：常态无底色，悬停浮出 `hoverBackground` |
| 实底形态 | `filled(true)`：常态即带 60% 强度底色 |
| 危险变体 | `danger()`：悬停转 `dangerHoverBackground` + `dangerHoverText` |
| 禁用 | `disabledWhen(true)`：透明度 × 0.4，不响应点击 |

```java
new IconButton("\uE872", () -> remove(row)).danger()   // 行内删除
new IconButton("\uE5CD", this::close)                  // 关闭
new IconButton("\uE145", () -> add()).size(20)         // 小号添加
```

## 六、`ButtonRow` 规格

作为 `CompactElement`，可直接放进模块页（`CompactModulePage.addCore / addFooter`）或折叠区。

| 能力 | 说明 |
| --- | --- |
| 满宽单按钮 | `new ButtonRow(button)` —— 撑满整行，对应旧项目 `addUniformButton` 的一行一个按钮 |
| 等宽多按钮 | `new ButtonRow(b1, b2)` —— 剩余宽度平分，对应确认框「确认 / 取消」、点位卡「设置 / 删除」 |
| 混排 | `Button` 参与平分，其它控件（如 `IconButton`）保持自身宽度、按行高居中 |
| 间距 | 默认 8，可 `new ButtonRow(12f, ...)` 指定 |
| 最小按钮宽 | 24，防止按钮过多时被压成一条 |
| 行高 | 每帧取子控件最大高度，子控件按行高垂直居中 |

```java
addCore(new ButtonRow(
        new Button("全部", () -> setFilter(ALL)).selected(() -> filter == ALL),
        new Button("物品", () -> setFilter(ITEM)).selected(() -> filter == ITEM),
        new Button("实体", () -> setFilter(ENTITY)).selected(() -> filter == ENTITY),
        new Button("方块", () -> setFilter(BLOCK)).selected(() -> filter == BLOCK)));

addCore(new ButtonRow(
        new Button("上一页", this::prevPage).disabledWhen(() -> page == 0),
        new Button("下一页", this::nextPage).disabledWhen(() -> page >= lastPage)));
```

## 八、旧项目按钮用法对照

| 旧项目用法 | 新项目写法 |
| --- | --- |
| `addUniformButton(...)` 一行一个满宽按钮 | `new ButtonRow(new Button(原文, 原作用))` |
| 一行 2 个等宽按钮（查找并添加 / 取消） | `new ButtonRow(new Button("§a查找并添加", ...), new Button("§c取消", ...))` |
| 一行 4 个筛选按钮（全部 / 物品 / 实体 / 方块，选中态 `§a✓ `） | 4 个 `Button` + `selected(...)`，放进 `ButtonRow` |
| 一行 3 个方块状态筛选（方块·全部 / 方块·已确认 / 方块·未知） | 同上 |
| 分页行（上一页 / 页码 / 下一页） | `ButtonRow(上一页, 下一页)` + `SettingText` 显示页码 |
| 点位卡「设置 / 删除」 | `ButtonRow(Button("§a设置", ...), Button("§c删除", ...).danger())` |
| 列表行尾减号删除 | `new IconButton(删除码点, ...).danger()` |
| 危险按钮前后加分隔线 | 用 `GlassPanel.divider(...)` 或独立 `ButtonRow` 分区，保持「与普通按钮隔开」 |
| 确认框「确认（可定制文案）/ 取消」 | `ButtonRow(Button(确认文案, ...).danger(), Button("§7取消", ...))` |

文案一律照《旧项目 UI 资产模板》原文填写，包含 `§` 颜色码。
