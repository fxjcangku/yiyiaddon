**yiyiaddon 1.0 · 历史正式版**

紧急修复，更新实体信息、HUD 血量、聊天气泡、鞘翅飞行与岩浆钓鱼。

Minecraft **26.1.2 / 26.2 / 26.3** · 本页提供 **3 个 ZIP 安装包**。

> **刚刚发错版本了，请重新下载。** beta10 的包漏掉了本地已完成的多项功能；本版已把实体信息默认开启、26.3 简洁聊天修复与粒子适配全部打入三个安装包，并逐包核对类与 Mixin 数量。


已内置 Baritone，无需另装。ZIP 请先解压，再安装其中的 JAR。

<summary>本版更新亮点与完整记录</summary>

## 本次亮点

- **实体信息默认开启** → 首次安装即显示头顶装备、血量与名字，无需再手动打开。
- **HUD 血量显示** → 直观查看目标生命、实时 3D 模型、装备与已同步效果。
- **抑制气泡聊天** → 默认抑制已识别的服务器聊天气泡，可自行恢复显示。
- **鞘翅飞行四模式** → 群系寻路、自动回坐标、方向寻路、坐标寻路。
- **星露谷岩浆钓鱼** → 岩浆抛竿与 Shift 小游戏，沿用补给和卸货设置。

## 详细更新记录

按模块展开，查看该版本的原始更新内容。

<details>
<summary><strong>更新概要</strong></summary>

- **概要**：正式版 1.0 收口；紧急修复 beta10 漏功能，恢复 26.3 简洁聊天，实体信息改为默认开启。

</details>

<details>
<summary><strong>修复</strong></summary>

- **发错版本** → beta10 包漏掉实体信息粒子、简洁聊天与默认开关等最新代码；本版三线重新构建并核对。
- **简洁聊天（26.3）** → 服务端把 § 颜色码作为普通字符下发，时间与姓名边界跨过这些码后恢复转换。
- **实体信息默认开启** → 无历史记录时默认打开；老档中显式关闭的仍按记录保留。
- **HUD 唤起与保留** → 通知收起后不出现、目标移开就消失，现看向实体自动唤起并保留已选玩家。
- **头顶信息排版** → 名字与血量分行居中，年龄只显示一次，血量按 0.5 变化、整数不带 .0。
- **物品与详情显示** → 无耐久物品不再误标耐久；装备长文改为点击详情弹窗，不再遮挡信息。
- **聊天显示** → 简洁模式补齐称号与徽章过滤；重复名牌、血量与气泡按来源抑制，气泡可恢复。

</details>

<details>
<summary><strong>新增</strong></summary>

- **实体信息 HUD** → 实时 3D 模型与信息卡，装备点击可看原版与自定义附魔、属性详情。
- **附近玩家选择** → 准星优先，移开后保留所选玩家，聊天头像可点击切换。
- **攻击距离联动** → 碰撞短角框、刻度环与射线同步 HUD，颜色可调、各项可分别关闭。
- **鞘翅飞行四模式** → 群系探索、自定义返航、方向巡航或填写坐标，目的地与飞行设置集中配置。
- **星露谷岩浆钓鱼** → 白针跟随绿区的 Shift 小游戏，等待服务器结算，沿用原后勤设置。

</details>

## 使用与验证边界

- **实体数据**：只显示服务器已同步的皮肤、装备、附魔与效果；隐藏属性不推算。
- **距离显示**：战斗可视化与 HUD 联动默认开启，实际命中仍由服务器判定。
- **鞘翅飞行**：需可用鞘翅；正常消耗模式另需至少 64 枚无爆炸效果原版烟花。
- **岩浆钓鱼**：需服务器支持与适配鱼竿，可自行关闭 Shift 小游戏。
- **验证范围**：三线均通过编译与混淆产物核对；26.3 简洁聊天已在开发客户端实机验证。
- **版本范围**：支持 26.1.2／26.2／26.3，按游戏版本分包，原配置保留。

### 运行环境与安装

- **全版本环境**：Windows x64 · Java 25 · Fabric Loader 0.19.5 及以上。
- **安装**：退出游戏，将 ZIP 内 JAR 与对应 Fabric API 放入 `mods`，移出重复旧 JAR。
- **入口**：默认按 **G** 打开界面；已内置 Baritone，无需另装。
