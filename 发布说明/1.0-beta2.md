**1.0-beta2 · 公开测试版** — 集中完善星露谷农场：满仓处置、变异作物收割与洒水器维护。

**项目刚移植，部分模块与模式未测试，遇到 BUG 请反馈。**

## 1. 更新日志

- **修复 · 满仓处置**：背包满时先卸货；无法腾出空间时停机，产物箱满时关闭模块。
- **修复 · 作物收割**：正确识别变种外观，使用最快工具按服务端进度清理枯苗、杂物与变种。
- **修复 · 成熟学习**：特殊变种无需人工标记；成熟学习一次确认，同类提示不再连刷。
- **修复 · 启动条件**：浇灌、施肥、药剂与洒水器维护缺少配置时，立即提示并拒绝开启。
- **修复 · 区域管理**：先完成当前地块；错位格显示红框，清理后消失；删除最后区域时取消对应作物。
- **修复 · 洒水器**：移除或换型后不再继续维护；删除区域时同步清除点位和方框。
- **修复 · 界面与说明**：记住上次页面，修正缩放图标外溢、肥料药剂中文名及种子补货说明。
- **修复 · 更新提示**：正式版不再提示下载测试包。
- **变更 · 变种学习**：按服务器、变种分别记录收割动作与工具，同服复用、跨服隔离。
- **变更 · 操作方式**：G 键开关界面；选择器默认展开首组，自动骨粉目标改为手动勾选。
- **变更 · 资源与指令**：资源默认原版处理，可选留档；种植区域补全先列作物，管理操作归入「管理」。

## 3. 运行环境

**环境**：Java 25 · Fabric Loader 0.19.5 及以上

**安装**：解压 ZIP，将 JAR 与对应 Fabric API 放入 `mods`；两条版本线不可混用。

**寻路**：已内置 Baritone，请勿重复安装。

## 4. 使用提醒

**支持范围**：仅 26.1.2 / 26.2，26.3 及以后暂不支持。

**测试建议**：使用独立实例，提前备份存档与配置；Beta 不代表所有模块与服务器均已验证。

**服务器使用**：先确认服规与管理员许可；自动化可能受反作弊限制，不保证免处罚。

**运行建议**：先小范围测试并核对范围与容器；出现拉回、警告或异常立即停止相关模块。
