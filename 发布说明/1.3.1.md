## 本次亮点

- 移除设备密钥生成、签名挑战及对应后台管理项，通过设备摘要登记并连接后台。
- 保留设备锁定、单模块权限、在线统计与钓鱼验证码审批，现有有效授权按账号和设备延续。
- 四个 Minecraft 版本继续分别提供 Windows x64 与 Mac x64 独立安装包。

**分系统安装包**：按四个 Minecraft 版本分别提供 Windows x64 的 win64 与 Mac x64 的 mac64 独立混淆 JAR，共八包。请按实际游戏版本和系统选择对应文件，不能将 Windows 包或历史 desktop 包改名当作 Mac 包。

> 已内置经过调教优化的 Baritone，请卸载自行安装的 Baritone，避免重复加载或冲突。

1. 核对 Minecraft 版本和运行系统，再选择同一版本对应的 win64 或 mac64 JAR。
2. 退出客户端，将旧版或重复的 yiyiaddon JAR 移出该实例的 mods 目录，只保留一份匹配的新包；原有配置按原路径保留。
3. 安装匹配游戏版本的 Fabric API，Fabric Loader 使用 0.19.5 或以上。
4. Mac 使用原生 ARM64 Java；1.21.11 选 Java 21，26.x 选 Java 25。
5. 启动后核对界面中的模组版本和 Minecraft 版本，再按服务器规则使用原有功能。

## 兼容与运行

- 本次 1.3.1 的 Mac 26.2 最终安装包已在独立 Fabric 单人实例完成世界载入、Skija 原生库加载与29项界面断言。该结果只对应本次实际成品，不沿用旧1.3的验收结论，也不代表真实服务器业务已通过。
- Windows 实机及其余三个游戏版本的 Mac 实机尚未验证。
- 本机驱动不支持 GL_EXT_window_rectangles，完整构建中的窗口矩形图形回归未通过，不将内容门禁或上述 Mac 实测写成完整构建全部通过。
- Mac 上的独立钓鱼长期安装凭据存储仍不可用，现有实现依赖 Windows DPAPI；该钓鱼功能边界保留，不影响新版正常心跳连接。
- 四版本八个真实混淆 JAR 已通过包内容、混淆、唯一系统原生库、二进制架构与元数据检查；GitHub 上传后的文件大小及服务端 SHA-256 与冻结清单全部一致。八个公开地址均已实际完整下载核对，SHA-256 与本地冻结产物全部一致。
- 设备指纹用于登记与权限管理；设备锁定、模块权限和钓鱼审批保持各自原有作用，不互相替代。
- 自动化功能仍受服务器规则、权限、网络和玩法条件影响；宣传封面为功能概念图。
