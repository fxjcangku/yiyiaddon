**1.0-beta3 · 公开测试版** — 新增种子挖矿，让矿物预测、真实验证与自动采掘连成完整流程。

**项目刚移植，部分模块与模式未测试，遇到 BUG 请反馈。**

## 1. 更新日志

- **新增 · 种子挖矿**：输入种子，本机离线预测矿物位置，验证可靠后联动自动挖矿。
- 主世界 8 种、下界 3 种矿物；每次采掘一种。
- 预测不读取玩家世界；独立计算进程随功能关闭而停止，已预测位置持续对照真实方块。
- 先验证种子再使用目标；换维度清除旧证据，下界独立验证。
- **修复 · 挖矿目标（3 项）**：伪装矿不再被直接丢弃，战斗目标框跟随实体，种子验证不再持续卡住。
- **修复 · 移动（1 项）**：恢复自动挖矿与星露谷农场的走路提速效果。
- **修复 · 图标与名称（4 项）**：修正洒水器图标、自建作物与蘑菇中文名、学名档案加载及盆型名称截断。
- **修复 · 季节（1 项）**：修正部分服务器季节始终显示未知的问题。
- **修复 · 传送（2 项）**：短距离连续传送不再误判拉回；调试框按时消失。
- **修复 · 名单（1 项）**：管理员白名单按服务器隔离，不再带入上一服的 NPC。

## 3. 运行环境

**环境**：Java 25 · Fabric Loader 0.19.5 及以上

**安装**：解压 ZIP，将 JAR 与对应 Fabric API 放入 `mods`；两条版本线不可混用。

**寻路**：已内置 Baritone，请勿重复安装。

## 4. 使用提醒

**支持范围**：仅 26.1.2 / 26.2，26.3 及以后暂不支持。

**测试建议**：使用独立实例，提前备份存档与配置；Beta 不代表所有模块与服务器均已验证。

**服务器使用**：先确认服规与管理员许可；自动化可能受反作弊限制，不保证免处罚。

**运行建议**：先小范围测试并核对范围与容器；出现拉回、警告或异常立即停止相关模块。
