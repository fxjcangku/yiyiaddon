## 3. 运行环境

- **环境**：Java 25 · Fabric Loader 0.19.5 及以上
- **安装**：解压 ZIP，将 JAR 与对应 Fabric API 放入 `mods`；两版不可混用。
- **寻路**：已内置 Baritone，请勿重复安装。

## 4. 使用提醒

- **支持范围**：仅 26.1.2 / 26.2，26.3 及以后暂不支持。
- **测试边界**：服务器资源、长挂机及跨设备导入待实机复测。
- **试用建议**：备份存档配置，少量物资试用；遵守服规，异常时停模块。
