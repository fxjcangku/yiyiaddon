**1.0-beta5 · 公开测试版** — 自动村民交易与自动附魔服务器适配修复。

## 1. 更新日志

- **修复 · 村民交易**：出售方向达到卸货阈值时会先把绿宝石送入卸货箱，再继续交易或等待补货。
- **修复 · 村民交易**：交易过程中打开背包不再误停机，关闭背包后流程继续。
- **修复 · 村民交易**：补货等待、候选为空和搜索结束提示会显示职业与任务物品。
- **变更 · 村民交易**：取货与卸货改为更快的连续搬运，并保留服务端回滚和重开箱兜底。
- **新增 · 村民交易**：寻路交易复用公共加速与拉回降档保护，关闭模块后会清理临时加速。
- **修复 · 聊天**：补全中文聊天指令和在线玩家参数；跨服来信改为顶部横幅显示。
- **修复 · 自动附魔**：自定义模式可从服务器菜单「更多附魔 → 附魔大全」读取带“诅咒”字样的菜单条目。
- **变更 · 自动附魔**：自定义附魔目标与服务器诅咒附魔书分组显示；诅咒书匹配后会跳过并送入废书箱。
- **变更 · 自动附魔**：服务器诅咒名单支持等待时长设置、附魔书图标和手动补充；其他模式不显示该专用入口。

## 3. 运行环境

**环境**：Java 25 · Fabric Loader 0.19.5 及以上

**安装**：解压 ZIP，将 JAR 与对应 Fabric API 放入 `mods`；两个游戏版本不可混用。

**寻路**：已内置 Baritone，请勿重复安装。

## 4. 使用提醒

**支持范围**：仅 26.1.2 / 26.2，26.3 及以后暂不支持。

**测试建议**：先备份存档与配置，在独立实例及少量物资下试用；Beta 不代表所有服务器已验证。

**服务器使用**：先确认服规与管理员许可；自动化受反作弊限制，不保证免处罚。

**异常处理**：出现拉回、警告、错误出售或异常移动时，立即停止相关模块并反馈。
