**本版重点**
- **极品装备合成（第五模式）** → 空手取工具箱与成品书箱材料，多工具按各自方案逐件合成后统一入箱；支持纯合成与挂机补经验。
- **四模式分类卸货** → 同词条跨等级共箱、命中后立即卸货并返回工作点；连续绑箱、HUD 同步，全程禁挖禁搭。
- **附魔提速** → GUI 操作延迟默认 0 刻，附魔速度大幅提升；依赖服务端回执的校验全部保留。

## 1. 更新日志
- **概要**：新增第五模式与分类卸货；修复砂轮取回、寻路、停用收尾与低配掉帧点击；附魔提速。

### 星露谷钓鱼
- **修复**：低配/掉帧时 HUD 帧抖动让小游戏精确时机整杆算不出点击 → 本杆始终无解且距收杆 ≥1.5 秒时按当前指针兜底点击一次（一杆一次，经原有全部安全门）。

### 极品装备合成（第五模式）
- **新增**：空手从工具箱、成品书箱取料 → 多工具按各自方案逐件铁砧合成并统一入箱，不用个人同款工具。
- **新增**：两种运行方式 → 纯合成与挂机循环；经验不足保留原件与步骤，补经验后继续同一件，不重领、不串方案。
- **修复**：真实已注册的自定义附魔被一律拒绝 → 识别、缺料、整件规划与成品核对统一用真实附魔身份，按精确等级加工。
- **修复**：备用铁砧按旧朝向放下后停机 → 补放前先同步放置朝向，原位置与绑定朝向校验不放宽。
- **修复**：错误等级、会转移额外词条或无关书料被误收 → 按规则排除并说明原因，缺料项目不消费、不虚报完成。

### 自动附魔与分类卸货
- **新增**：四模式分类卸货 → 同词条跨等级共箱、目标等级另判；勾选种类进专箱，其余可收成品进公共箱。
- **新增**：目标选择器与保存清单 → 支持搜索、直接编辑、批量添加；完成后剔除只改本轮待办，不删保存目标。
- **修复**：自定义附魔在服务器砂轮取回时因产物组件变化错误停机 → 按真实返回结果确认。
- **修复**：自定义装备砂轮洗练后卡住不取回 → 改按服务端完整回执与物品守恒确认真实产物后取回。
- **修复**：活板门、半砖、地毯等非整方块旁寻路失败停机 → 站位改按真实碰撞顶面判定。
- **修复**：快捷键停用后容器交互一直被占用 → 当前书与材料沿原流程安全归还，原笔只结算一次。
- **修复**：死亡回主城后向遥远旧工作点寻路 → 启动时距工作点超过 128 格先自检拦截，保留原点位。
- **修复**：已有自定义成品入箱、本轮加工 0 次时无法保存记录 → 可保存，且不虚增附魔次数、青金石或等级消耗。
- **优化**：归还确认等待期间继续有限读回完整库存 → 保留原三次读回预算，不重发加工、不凭超时解除保护。
- **优化**：GUI 操作延迟默认由 1 改为 0、范围放宽 0~10 → 附魔速度大幅提升，想放慢把延迟调大即可。



### HUD、播报与 Buff 加成
- **修复**：无当前有效任务时打开聊天恢复历史任务卡 → 不再恢复，保留手动隐藏，撤销失效卡片的点击与滚轮捕获。
- **优化**：修饰符大全更名为 **Buff 加成** → 补齐列表与属性物品图标，功能、作用与兼容性说明分区，宽窗两列、窄窗一列。
- **优化**：记录与物品列表 → 支持按模块名、标题、正文搜索与分类共同筛选，新增上/下翻页与页码。
- **优化**：统计配色 → 命中、入箱、刷新分别用绿、蓝青、琥珀色圆角框，深浅主题自适应，设置宽屏分栏、窄窗回排。

## 3. 运行环境
- **环境**：Windows x64 · Java 25 · Fabric Loader 0.19.5 及以上。
- **安装**：退出游戏，将 ZIP 内 JAR 与对应 Fabric API 放入 `mods`，移出重复旧 JAR。
- **入口**：默认按 **G** 打开界面；已内置 Baritone，无需另装。

## 4. 使用提醒
- **等级目标**：`利刃2+` 至少二级、`利刃2` 仅二级、`利刃` 任意等级；第五套为精确正整数，不能写 `2+`。
- **成品与来源**：前四模式箱满或不可达会停止；第五套成品箱不足则保留队列等待，只加工符合条件原件。
- **Buff 加成**：页面与 HUD 显示客户端属性，实际结果由服务器判定；**不是所有服务器都可以使用，请自行测试**。
- **附魔提速**：默认 0 刻为每刻连续推进；依赖服务端回执的校验仍全部保留，寻路与装备砂轮取回已获用户实机确认。
- **测试范围**：两版第五套与四模式分类卸货已在隔离单机场景通过；原服插件、长期挂机与拾书分支未复测。
- **版本范围**：26.1.2 / 26.2 分包，26.3 测试中暂无下载。
