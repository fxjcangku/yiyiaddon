## 本次亮点

- **全自动地图画新增「平面方块地图画」模式**：配置顶部支持「地毯 / 平面方块」切换，导入单层 `128×128` 的 NBT、Litematic 与 Schem 投影；双模式各自保留投影、锚点、材料绑定与断点，支持施工高度 Y 与 128 格四向平移预览，步行与飞行沿中线连续施工，口粮与材料接入快速整组补货。
- **统一点位绑定引导与 30 秒动态倒计时**：全模块点位绑定统一顶部居中圆角玻璃卡片，零标点符号、带左右键键帽与 30 秒实时递减倒计时进度条（低余量转琥珀预警，超时自动暂停保留已完成点位）；连续设点自动跳过前置未就绪项并即时关闭清单界面。
- **星露谷农场大修与独立定点农场**：新增 5×5 独立定点农场（品质分箱、漏斗与矿车投放）；修复缺种退避锁死区域、大田熟菜拖慢、中线停顿、卸货到站不开箱、空壶安全补水与资源包 `range_dispatch` 下空容器回收箱缺图标。
- **全套圆角玻璃界面、HUD 与聊天增强升级**：主面板、分页配置、圆角玻璃聊天框与 1.5 新版更新弹窗焕新，任务 HUD 固定右下角支持独立拖宽，原版主菜单支持新版本提醒，管理员上线检测新增在线名单预警开关，全模块取证统一按模块与时间命名并自动打开日志目录。
- **首页、农场与改种修复**：首页双列按较矮一侧分配后续卡片，减少收藏较多时左下大片空白；面板与高缩放窗口顶部提示卡随面板稳态倍率缩放不再超大遮挡；星露谷大田重构八排蛇形状态机，改进连续水播与部分卸货。停机空田可直接换作物，目标名单和区域名称同步更新。

## 详细更新记录

<details open>
<summary><strong>全自动地图画</strong></summary>

- **新增** 在配置顶部切换地毯或平面方块。可导入单层 128×128 的 NBT、Litematic 和 Schem 投影，材料箱按实际物品绑定，施工核对方块状态。
- **新增** 预览时可选施工高度 Y、向四个方向整幅平移 128 格，再确认西北角。两种模式分别保存投影、锚点、材料绑定和断点，共用食物箱、地图用品箱和制图台。
- **优化** 步行和飞行都可沿中线连续施工。口粮、地毯与方块材料按整组补给；锁图用品按需取一张空地图和一块透明玻璃板。
- **修复** 退出地图画与选点后会收起世界标记。区块加载完毕后，大箱子会重新显示完整边界。保留西北角、首带入口和箱体字牌，移除材料箱与工作站射线。
- **优化** 投影路径输入框会随窗口伸缩，选择、导入和移除按钮等宽排列。

</details>

<details>
<summary><strong>区域改种与箱子</strong></summary>

- **修复** 停止农场后也能给已加载的空区域换品种。新品种可从本服已识别的作物中选择，保存后自动加入目标作物。旧品种只有在本服所有维度都没有其他固定区域使用时才会取消勾选。
- **修复** 改种保留田区角点。田里还有作物时会提示品种和坐标，收掉或挖掉后再改。区块或资源信息不足以确认空田时，先保留原品种。
- **优化** 圈地选品种时突出显示格数，坐标范围使用文字；作物每页按 3×3 平铺，支持全量搜索和翻页，少量候选自动收拢。种子库继续使用原来的选择界面。
- **说明** 种子箱按作物绑定。启用种子补给后，新品种若已有绑定就可继续用，缺少时须为它选箱。多种作物可以分别指定同一个实体箱。
- **说明** 普通卸货先用新品种自己的卸货箱，缺省时可用已有的公共卸货箱。启用品质分箱时按新品种配置对应品质箱。原作物的专用箱保留在原作物名下。

</details>

<details>
<summary><strong>普通农场与定点农场</strong></summary>

- **修复** 大田沿八排蛇形条带作业，浇完身边可达干盆再播湿盆。回补、洒水器维护和补给结束后从原带原方向接续，减少漏边、来回折返、切手停顿及整田反复扫描。
- **修复** 逐盆等候出苗与耗种回执，等候时照料其他可达格。修复身后湿盆与前方干盆互相等待、刚播出的幼苗挡住起步以及洒水器已浇湿仍反复点击的问题。
- **修复** 大田出现熟菜后优先采收，附近湿空盆顺手补，干熟作物先浇再收。种子箱缺货只暂缓对应播种，采收、拾取与其他区域继续工作。
- **修复** 空壶优先尝试田内及周围能安全交互的静水，再走绑定补水点。暂时没有水源时保留待浇位置，补满后接回原盆。
- **修复** 卸货到站但够不到箱面时会换站位并保留本批物品。部分卸货减少拆组点击，默认卸货门槛为 8 组即 512 个，原有自定义数量和单位继续使用。
- **优化** 错种红框贴合实际植株；修复部分资源包下空容器回收箱标记缺少玻璃瓶和空桶图标的问题。
- **新增** 独立定点农场按序管理 5×5 地块，可绑定中心、水源、补给与输出，按本服已确认的收法处理普通或巨大作物，支持品质分箱、漏斗和矿车投放。

</details>

<details>
<summary><strong>点位绑定与弹窗</strong></summary>

- **修复** 连续设点松开上一击即可确认下一项，绿色保存回执可继续显示。遇到前置条件未满足的项目会说明原因并跳到下一项。
- **优化** 点位、区域角点、站位朝向、抛竿选区与容器均在顶部居中显示目标、按键和 30 秒倒计时。换步或重试后重新计时，选择作物期间暂停，到期保留已设点位。
- **修复** 点位回执、失败原因和自检提醒会避开服务器 Boss 栏。公共长内容弹窗按正文需要展开，修复高缩放下更新提示过小、容器列表被压缩、装备配置双层滚动及清单与长说明截断的问题，更新提示的操作按钮保持可见。
- **修复** 高界面缩放和小窗口下，顶部提示会随当前面板缩放，为首页标题、聊天操作和原版提示留出空间。

</details>

<details>
<summary><strong>界面、任务 HUD 与更新</strong></summary>

- **优化** 主面板、配置分页、设置、工作台和帮助统一圆角玻璃布局，随窗口大小和全屏重新排版。支持在多人选服页使用已绑定快捷键打开与返回，控件响应减少动画设置。
- **修复** 钓鱼等模块切页时导航稳定，模块标题与开关同排，快捷键设置更易点选。窄版实体观察有足够空间显示数值和单位。
- **修复** 首页双列会把后续卡片排到较短的一列，窄屏使用单列。公告、常用操作、身份、在线人数与每小时活跃集中展示。
- **优化** 任务 HUD 固定右下角。统计框统一使用自动附魔的紧凑尺寸；避让小地图后用足实际高度，并按界面档位缩放展示完整运行数据。打开聊天可调整栏宽与大小，三种布局分别记忆栏宽。
- **新增** 检测到适配当前游戏版本和系统的正式新版时，无论当前处于主菜单、游戏世界或其他界面，都会自动弹出更新提示。同次启动对同一目标版本只提醒一次，使用已设计的版本对比、更新说明和下载按钮。
- **新增** 农场与钓鱼配置页提供独立资源管理窗口，集中查看资源状态、来源及缓存详情。准备中与已就绪提示可直接区分。
- **新增** 管理员检测可按服开启在线名单预警，即使目标不在附近也可按已有规则主动断线。该选项默认关闭，白名单优先。

</details>

<details>
<summary><strong>星露谷钓鱼与问题取证</strong></summary>

- **优化** 钓鱼地图验证按服务器提示区分数字、字母与混合，保留大小写、前导零及重复字符。支持在聊天中放大查看原图，经服务器确认成功后才记录本服字形。
- **修复** 补齐部分资源包中只有原版鱼竿模型分支的钓具预览，以及能辨认的资源中文名称。
- **优化** 在模块设置顶部可复制开始和停止取证指令。钓鱼取证统一使用中文入口，可按验证码、小游戏或岩浆分类。
- **优化** 取证 ZIP 使用模块名和开始时间命名，停止或导出成功后打开所在目录，并保留再次打开入口。长时间运行时滚动保留近期明细，摘要区分采样与丢弃记录。

</details>

<summary><strong>聊天与频道</strong></summary>

- **优化** 圆角玻璃聊天框随界面档位、窗口和全屏调整，保留手动尺寸、草稿、原版输入与补全。频道发送回执直接显示在聊天面板。
- **修复** 来自系统消息且带可核对姓名头像的私聊，可在新消息与旧历史中正确归栏。保留原文、时间及原有消息交互。
- **修复** 聊天面板清屏时保存并恢复窗口矩形状态，减少图形状态残留对后续画面的影响。

</details>

- **优化** 后台合并重复心跳和版本写入。官网今日人数与小时记录区分真实零和采集中断，采集短暂失败会重试；已有读数的小时保持连线，真正未记录的时段仍留空。手机网络不稳时可查看最近有效的发行目录及核验时间。
- **修复** 官网备用线路可处理客户端的正式请求。后台头像按账号加载，切换对象后会忽略迟到的旧响应；公告、反馈与手机列表操作已整理。

## 使用与反馈

建议 1.4 及更早版本用户升级至 1.5：退出游戏后移出旧版 JAR，放入对应游戏版本与系统的 1.5 安装包，原有配置、点位与映射自动保留。

反馈问题时请提供 Minecraft 版本、模组版本、操作系统、复现步骤及导出取证 ZIP（取证文件可能包含服务器地址与坐标，请私下发送）。

取消勾选作物会保留已划分区域。作物独立箱只可按当前作物与用途解绑，其他作物和公共箱保持原绑定。解绑某个品质箱后，品质勾选仍保留，继续使用该品质的分类卸货时需要重绑。

**分系统安装包**：四个 Minecraft 版本分别提供 Windows x64（`win64`）与 Mac x64（`mac64`）两个独立混淆 JAR，共八包。请按实际游戏版本和操作系统选择匹配文件，不要将不同系统或历史 `desktop` 包改名混用。

Mac x64 为页面展示名称，实际为 **macOS ARM64（Apple Silicon）**，须搭配原生 ARM64 Java，不支持 Intel Mac；Windows ARM64、Linux 与 Android 不在本次分系统安装包支持范围。

> 已内置调教优化的 Baritone，请先卸载自行安装的 Baritone，避免重复加载或冲突。

1. 核对 Minecraft 版本和操作系统，选择匹配的 `win64` 或 `mac64` JAR。
2. 退出客户端，移出 `mods` 目录中的旧版或重复 yiyiaddon JAR，仅保留一份对应新包；原有配置自动保留。
3. 安装对应游戏版本的 Fabric API，Fabric Loader 使用 `0.19.5` 或以上。
4. 1.21.11 使用 Java 21，26.x 使用 Java 25；Mac 均须使用原生 ARM64 Java。
5. 启动游戏后核对界面版本号，按服务器规则使用各项功能。

## 兼容与验证范围

- 四个游戏版本的 Windows x64 与 Mac x64 共八个混淆 JAR 按对应分支独立构建，逐包核对版本、Java 要求、唯一系统原生库、二进制架构和 SHA-256。
- 最终 26.2 Mac x64 安装包在 Apple Silicon 原生 Java 25 的独立 Fabric 单人实例中通过 46 项 UI 断言，确认从本次成品加载界面与 ARM64 Skija，并完成世界保存、重新进入及正常退出。其他三个游戏版本的 Mac 成品及 Windows 原生实机仍待分别验证。
- 本轮 26.2 开发客户端单人验证了四项紧凑统计框、四种作物详情、真实小地图避让、自动 GUI 8 与 GUI 2、深浅主题和完整正文无滚动条。统计展示数据来自独立排版夹具，该结果不作为服务器农场业务验收。
- 圈地选择作物另经原资源包单人验证，18 种作物按 3×3 两页平铺、全量搜索、真实建区落盘及取消不建区通过。地图画和其他农场业务的既有验证范围见 1.4 记录，本轮没有重新执行全部模块或多人原服流程。
- 26.2 完整构建以及 HUD、设置和更新弹窗相关回归通过。其他三线保留各自 API、映射和 Java 差异；本轮正式八包的逐包静态检查和实际下载校验以文件表为准。
- 原生窗口矩形像素专项仍需要支持 GL_EXT_window_rectangles 的驱动；Mac 上钓鱼长期安装凭据仍受 Windows DPAPI 存储机制限制。
